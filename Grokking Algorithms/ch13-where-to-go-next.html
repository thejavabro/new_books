Linear regression

Pricing a 3,000 ft² house? Plot recent sales by size and price, fit a straight line through them, and read off where your size lands. Linear regression finds the line that best fits the points. It's an old statistics tool and a common first try in machine learning, useful when the value you predict is continuous.

3

Inverted indexes: how search starts

A search engine can't read every page for every query. Instead it builds a hash table from each word to the pages it appears on. Searching is then a lookup. Because it maps words to locations, the reverse of a page listing its words, it's called an inverted index.

The Fourier transform: what's in the smoothie?

Given a smoothie, the Fourier transform tells you its ingredients. Given a sound, it tells you which frequencies it's made of and how much of each. That lets you boost the bass, drop inaudible parts to compress music (the idea behind MP3; JPG does something similar for images), identify songs, or analyze earthquakes and DNA. Parallel algorithms and Amdahl's law

Computers stopped getting much faster per core; instead they got more cores. To go faster, algorithms must run in parallel. A parallel quicksort can even sort in O(n) time. But speed-ups are never linear: splitting work and merging results costs time, work must be load balanced so no core sits idle, and Amdahl's law limits the gain to the part you actually sped up. Speed up a quick sketch and a 20-hour painting barely changes.

map/reduce: spread the work across machines

When a job needs hundreds of cores, spread it across many machines with a distributed algorithm. map/reduce, popularized by Google, has two steps built from two familiar functions. map applies a function to every item independently, so each machine can take a share. reduce boils many results down to one. Bloom filters and HyperLogLog

Has this URL been crawled? Has this link been posted before? Is this site on the malware list? A hash table answers exactly but must store every URL: huge. A Bloom filter is a probabilistic structure: a row of bits plus several hash functions. Adding an item sets the bits its hashes point to. Checking an item looks at those bits: if any is 0, the item was definitely never added; if all are 1, it was probably added. False positives are possible, false negatives are not, and it takes very little space.

HyperLogLog plays the same trick for counting: it estimates how many unique items you've seen (unique searches today, unique products viewed) using a tiny fraction of the memory an exact log would need. If you have lots of data and an approximate answer is fine, look into probabilistic algorithms.

8

HTTPS and the Diffie–Hellman key exchange

HTTPS encrypts traffic with a key both sides share (symmetric encryption). But how do you agree on a key when anyone might be listening? Diffie–Hellman does it without ever sending the key. The classic picture mixes paint: mixing is easy, un-mixing is practically impossible.

HTTPS uses ephemeral Diffie–Hellman: fresh private keys for every connection, so a leaked key exposes only one session. The protocol is TLS; "SSL" is its old, broken predecessor's name, still used loosely. For much more, the book recommends Real-World Cryptography by David Wong.

9

Locality-sensitive hashing

A cryptographic hash such as SHA-256 is locality-insensitive: change one character and the hash changes completely, so attackers learn nothing from comparing hashes. Sometimes you want the opposite. Simhash is locality-sensitive: similar inputs give similar hashes, so comparing hashes tells you how alike two texts are. Useful for spotting duplicate pages while crawling, copied essays, or uploads of copyrighted books.

Min heaps and priority queues

A min heap is a tree where every parent is smaller than its children, so the smallest value is always at the root: you can peek at it in O(1), and remove it in O(log n) while the heap repairs itself. Keep removing the minimum and you get a sorted list: that's heapsort. (A max heap keeps the largest on top.) Heaps are the natural way to build a priority queue, a queue that always hands you the highest-priority item, such as a to-do app, or a faster Dijkstra.

Saved for last: linear programming maximizes something subject to linear constraints. A shop makes shirts and totes.
