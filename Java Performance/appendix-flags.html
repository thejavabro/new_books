How to use this table

The book closes with a list of every flag it discusses. This page regroups them by area with a one-line, plain-language note on what each does and when it is worth touching. Defaults are for JDK 8 and 11 HotSpot on 64-bit Linux unless noted; always confirm on your own JVM with java -XX:+PrintFlagsFinal -version.

The golden ruleMost of these should stay at their defaults. Change one only to fix a problem you have measured, change one at a time, and test the result statistically (chapter 2).
