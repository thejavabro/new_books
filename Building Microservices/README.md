# Building Microservices, Drawn Out

A visual, interactive companion to *Building Microservices: Designing Fine-Grained Systems* (2nd edition, 2021) by Sam Newman (O'Reilly). There is one self-contained HTML page per chapter, with clickable diagrams, small simulations, a short quiz (3 to 5 questions) and a recap.

## How to open

Unzip the folder and open `index.html` in any modern browser. Every page works offline. Links between pages are relative. Fonts load from Google Fonts when you are online; otherwise system fonts are used. Use the theme button in each page header to switch between light and dark.
