How text becomes bytes: UTF-8, UTF-16, UTF-32

Every character has a code point, a number in Unicode. An encoding decides how many bytes store it (P38). UTF-32 always uses 4. UTF-16 uses 2, or a 4-byte surrogate pair above U+FFFF. UTF-8 uses 1 to 4, and plain ASCII stays 1 byte. Inside the JVM, a String is stored either as LATIN-1 (1 byte per char, the "compact strings" of JDK 9) or as UTF-16. Type anything, emoji included.

Initialization-on-demand holder

A lazy, thread-safe singleton without synchronized or volatile (P45). The trick is that the JVM initializes a class only on first use, and class initialization is already guaranteed to run once, under a lock. Step through.

public final class Config {
    private Config() { /* expensive */ }

    private static class Holder {
        static final Config INSTANCE = new Config();
    }

    public static Config get() {
        return Holder.INSTANCE;
    }
}

An immutable stack shares its past

P50 builds a stack where push and pop return a new stack and never change the old one. Because each node only points down, a new version reuses every node beneath it. Nothing is copied, and old versions stay valid, which makes them safe to share between threads.

Blue nodes are shared with the previous version; green is the only new allocation.

record Stack<T>(T head, Stack<T> tail) {
    static final Stack<?> EMPTY = new Stack<>(null, null);
    Stack<T> push(T v) { return new Stack<>(v, this); }  // O(1), no copy
    Stack<T> pop()     { return tail; }                   // the old version is untouched
}
The same idea, as a classic bug (P51)String is immutable too, so name.trim(); on its own line does nothing: it returns a new string that nobody keeps. Write name = name.trim();.

Helpful NullPointerException messages

Since JDK 14 (on by default from 15) the JVM tells you which reference was null (P52). Choose which link of the chain is null and read the message you would get.

Local variable names appear only if the class was compiled with -g; otherwise you see <local1>. The message is computed lazily, only when someone calls getMessage().

Switch expressions, yield and case null

A switch expression produces a value, uses arrows that never fall through, and must cover every input. When a branch needs a block, yield hands back the value (P53). Since JDK 21 a switch can also take case null instead of throwing NPE (P54). Pick an input.
