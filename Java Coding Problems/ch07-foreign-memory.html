From JNI glue to plain Java

Calling C from Java used to mean JNI: declare a native method, generate a header, write C glue that converts types, compile a library per platform, then load it (P144). JNA and JNR remove the glue with reflection-like magic, at a performance cost (P145–P146). Project Panama's Foreign Function & Memory API (preview in JDK 21, final in JDK 22) does it in pure Java, as fast as JNI (P147).     Six types to learn
    
  
    The API is small (P148). Memory is a MemorySegment that lives as long as its Arena, described by a MemoryLayout. Functions are found with a SymbolLookup, described by a FunctionDescriptor and turned into a MethodHandle by the Linker.
    
  
    

    


    
  
    3
    Arenas decide when memory dies
    
  
    Native memory has no garbage collector, and JNI-era code leaked or double-freed it. An Arena ties a group of segments to one lifetime, and every access is checked: touching a segment after its arena closes throws IllegalStateException instead of crashing the JVM (P149). Pick an arena, allocate, close, then try to read.
    
  
    
    
    
    
    
    
    
    
    
  
    
  
    try (Arena arena = Arena.ofConfined()) {
    MemorySegment one  = arena.allocate(ValueLayout.JAVA_INT);
    MemorySegment many = arena.allocateFrom(ValueLayout.JAVA_INT, 1, 2, 3, 4);  // P150 (JDK 21: allocateArray)
    one.set(ValueLayout.JAVA_INT, 0, 42);
}   // all freed here, deterministically

    C structs, alignment and PaddingLayout
    
  
    A C compiler aligns each field to a multiple of its size and pads the struct to the largest alignment. When you describe the same struct in Java with MemoryLayout.structLayout, you must add those gaps yourself with MemoryLayout.paddingLayout(n), or the API rejects the misaligned layout (P153, P155). A union overlays all fields at offset 0 and takes the size of the largest (P154). Build a struct and reorder it to save bytes.

    5
    Slicing, sequence layouts, flattening and reshaping
    
  
    A sequence layout is an array type: sequenceLayout(10, JAVA_INT) (P152). asSlice(offset, size) gives a view of part of a segment without copying, and MemorySegment.copy moves bytes between segments (P156). A slicing allocator hands out consecutive slices of one big segment (P157). Nested sequences can be flattened into one dimension or reshaped into another (P159–P160); the bytes never move, only the view changes.
    
  
    
    
    
    
    
    
    
    
  
    
  
    SequenceLayout grid = MemoryLayout.sequenceLayout(3, MemoryLayout.sequenceLayout(4, JAVA_INT));
VarHandle cell = grid.varHandle(PathElement.sequenceElement(), PathElement.sequenceElement());
cell.set(segment, 0L, 1L, 2L, 99);                // grid[1][2] = 99   (P162 memory-segment view VarHandle)
SequenceLayout flat = grid.flatten();             // [12 x int]
MethodHandle offsets = grid.byteOffsetHandle(PathElement.sequenceElement(), PathElement.sequenceElement());
    
  
    

    


    
  
    6
    Calling C functions with the Linker
    
  
    A downcall calls C from Java: find the symbol, describe its signature with a FunctionDescriptor, ask the Linker for a MethodHandle, and invoke it (P165–P168). An upcall goes the other way: a Java method wrapped as a C function pointer, which is what bsearch needs for its comparator (P169). Step through a call to strcat.
    
  
    
    
    Linker linker = Linker.nativeLinker();
SymbolLookup libc = linker.defaultLookup();
MethodHandle strcat = linker.downcallHandle(
    libc.find("strcat").orElseThrow(),
    FunctionDescriptor.of(ADDRESS, ADDRESS, ADDRESS));

try (Arena arena = Arena.ofConfined()) {
    MemorySegment dst = arena.allocate(64);
    dst.setString(0, "Hello ");
    MemorySegment src = arena.allocateFrom("Panama!");
    MemorySegment r = (MemorySegment) strcat.invokeExact(dst, src);
    String s = r.reinterpret(64).getString(0);   // "Hello Panama!"
}
    
    
    
  
    
  
    jextract (P170–P171)Writing descriptors by hand for a big C library is tedious. jextract reads a C header and generates Java classes with ready-made method handles and layouts, for example jextract --output src -t c.lib.math /usr/include/math.h, after which modf is just a static Java method.
