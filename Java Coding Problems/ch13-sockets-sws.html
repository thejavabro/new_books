TCP and UDP: a phone call and a postcard

A socket is one end of a connection, named by an IP address and a port (P258). TCP opens a connection with a three-way handshake, then guarantees every byte arrives, once, in order, retransmitting what gets lost (P259). UDP just sends independent datagrams: no connection, no ordering, no retries, and much less overhead. Send six packets over a lossy network.

Blocking server vs non-blocking server

A blocking echo server (P261) calls accept(), then read(), and the thread waits at each step, so serving many clients means a thread per client. A non-blocking server (P262) registers every channel with a Selector, and one thread loops over select(), handling only the keys that are ready: OP_ACCEPT, OP_READ, OP_WRITE. Connect clients and send messages.

Thread per client (blocking)
One thread + Selector
Selector selector = Selector.open();
ServerSocketChannel server = ServerSocketChannel.open().bind(new InetSocketAddress(5555));
server.configureBlocking(false).register(selector, SelectionKey.OP_ACCEPT);
while (true) {
    selector.select();                                   // wait until something is ready
    for (Iterator<SelectionKey> it = selector.selectedKeys().iterator(); it.hasNext(); ) {
        SelectionKey key = it.next(); it.remove();
        if (key.isAcceptable()) accept(selector, key);   // register client for OP_READ
        else if (key.isReadable()) read(key);            // echo back via OP_WRITE
    }
}

P268: since JDK 13 the old java.net.Socket and ServerSocket run on a new NIO-based implementation (NioSocketImpl, JEP 353), which is also what lets them block a virtual thread without pinning a carrier.

UDP and multicast: one send, many receivers

A UDP server just binds a DatagramChannel and answers each datagram; a client may stay unconnected or call connect() to fix its peer (P263). Multicast sends one datagram to a group address (224.0.0.0 to 239.255.255.255), and the network delivers a copy to every member (P264). Receivers join on a chosen network interface (P265) and get a MembershipKey they can use to leave, or to block particular sources (P266). Toggle members and broadcast.

NetworkInterface ni = NetworkInterface.getByName("eth0");
DatagramChannel dc = DatagramChannel.open(StandardProtocolFamily.INET)
    .setOption(StandardSocketOptions.SO_REUSEADDR, true)
    .bind(new InetSocketAddress(4444))
    .setOption(StandardSocketOptions.IP_MULTICAST_IF, ni);
MembershipKey key = dc.join(InetAddress.getByName("225.4.5.6"), ni);
// key.block(source) / key.unblock(source) / key.drop()

Key Encapsulation Mechanism (JDK 21)

To encrypt a TCP conversation, both sides need the same secret key, and they must agree on it over an untrusted network. JDK 21's javax.crypto.KEM API (JEP 452) standardizes key encapsulation: the receiver publishes a public key, the sender derives a fresh secret and an "encapsulation" that only the private key can open (P267). The same API will host post-quantum algorithms. Step through the book's flow with DHKEM over X25519.

// receiver (client)
KeyPair kp = KeyPairGenerator.getInstance("X25519").generateKeyPair();
// sender (server), after receiving the public key
KEM.Encapsulated enc = KEM.getInstance("DHKEM").newEncapsulator(publicKey).encapsulate();
SecretKey secret = enc.key();          // use for AES
byte[] toSend = enc.encapsulation();   // send to the receiver
// receiver
SecretKey same = KEM.getInstance("DHKEM").newDecapsulator(kp.getPrivate()).decapsulate(toSend);

The Simple Web Server: jwebserver

JDK 18 (JEP 408) ships a minimal static file server for prototyping, testing and teaching: no CGI, no HTTPS, GET and HEAD only, directory listings included (P269). From the command line it is jwebserver (P270). Build a command.

Programmatically, com.sun.net.httpserver gained three building blocks (P271): SimpleFileServer for file handlers and servers, HttpHandlers for canned and conditional handlers, and Request to inspect or adapt a request before handling it (P272–P273). Try routing.

var files  = SimpleFileServer.createFileHandler(Path.of("/var/www"));
var health = HttpHandlers.of(200, Headers.of("Content-Type", "text/plain"), "OK");
var denied = HttpHandlers.of(403, new Headers(), "");
HttpHandler router = HttpHandlers.handleOrElse(
    r -> r.getRequestURI().getPath().equals("/health"), health,
    HttpHandlers.handleOrElse(r -> r.getRequestURI().getPath().startsWith("/admin"), denied, files));
HttpServer.create(new InetSocketAddress(8080), 10, "/", router).start();
