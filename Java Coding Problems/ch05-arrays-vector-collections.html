One instruction, many numbers

A classic loop adds one pair of numbers per instruction: Single Instruction, Single Data (SISD). Modern CPUs have wide registers (SSE 128-bit, AVX2 256-bit, AVX-512 512-bit) that add a whole chunk at once: SIMD (P107). The incubating Vector API (jdk.incubator.vector, since JDK 16) lets you write that in portable Java, and the JIT maps it to the best instructions the CPU has. Race them.

Shape, element type, species, lanes

A vector is a fixed-size sequence of lanes. Its shape is the size in bits; its element type is the Java primitive in each lane; the pair is the species, e.g. IntVector.SPECIES_256 (P108). Lanes = shape ÷ element size. SPECIES_PREFERRED picks the best shape for the running CPU.

3

Chunking an array: loopBound and the tail

To add two arrays (P109), step through them one vector at a time. species.loopBound(length) returns the largest multiple of the lane count that fits, so the vector loop never reads past the end. The leftover tail needs separate handling: a VectorMask that switches off lanes past the end, or a plain scalar loop. Masks in hot loops are expensive, so the scalar tail is usually preferred. Unrolling, processing several vectors per iteration, can help further (P110).

static final VectorSpecies<Integer> S = IntVector.SPECIES_PREFERRED;
static void sum(int[] x, int[] y, int[] z) {
    int i = 0, bound = S.loopBound(x.length);
    for (; i < bound; i += S.length())
        IntVector.fromArray(S, x, i).add(IntVector.fromArray(S, y, i)).intoArray(z, i);
    for (; i < x.length; i++) z[i] = x[i] + y[i];          // scalar tail
}
Benchmarks need care (P111)The book measures with JMH. Vector code only wins once the JIT has compiled it to real SIMD instructions; in the interpreter, or on a CPU without wide registers, it can be slower than the scalar loop. Run it with --add-modules jdk.incubator.vector.

Fused multiply-add, matrices and images

FMA computes a·b + c in one step with one rounding (P112). A dot product is a running FMA: sum = x.fma(y, sum) lane by lane, then reduceLanes(ADD) folds the lanes into one number. A matrix product is a dot product per output cell (P113). Step through a dot product with 4 lanes.

6

Sizing a HashMap for n entries

new HashMap<>(n) sets the number of buckets, not entries. The map resizes once size exceeds capacity × 0.75, rehashing everything (P117). To hold n entries without resizing you need about n / 0.75 buckets, which is what JDK 19's HashMap.newHashMap(n) computes for you. Internally the table size is also rounded up to a power of two. Try values.

7

Sequenced collections (JDK 21)

Before JDK 21, "get the last element" was list.get(list.size() - 1), deque.getLast(), sortedSet.last() or a loop for LinkedHashSet. JEP 431 added SequencedCollection, SequencedSet and SequencedMap with one vocabulary: addFirst/addLast, getFirst/getLast, removeFirst/removeLast and reversed() (P118). The implementations still differ in the details. Try them.
