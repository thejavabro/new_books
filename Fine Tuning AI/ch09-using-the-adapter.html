What is in the adapter folder?

Training ends with a folder on disk, and on Colab that disk disappears when the runtime disconnects. Before anything else, understand it and back it up. The whole folder is about 71 MB; the trained work itself is a roughly 39 MB file, because an adapter is a patch, not a model. Tap a file:

2

Inside a .safetensors file

The old PyTorch .bin format used Python's pickle, which can run arbitrary code when loaded. safetensors is deliberately boring: an 8-byte length, a JSON header naming every tensor with its dtype, shape and byte range, then raw numbers. Nothing executable, and you can read the header without loading the tensors.

Decode a tensor name

The stored adapter is float32 even though training used bf16=True: mixed precision casts computations, while master weights stay in full precision.

Get it off the runtime

from peft import PeftModel
base = AutoModelForCausalLM.from_pretrained("google/gemma-4-E4B-it", torch_dtype=torch.bfloat16, device_map="auto")
tok  = AutoTokenizer.from_pretrained("adapters/medical-qa-v1")
model = PeftModel.from_pretrained(base, "adapters/medical-qa-v1")   # or "you/repo" on the Hub
# optional: model = model.merge_and_unload()  (one-way: cannot be unmerged)

Loading walks the base model's modules and wraps every one named in target_modules with a LoRA layer holding A and B. For private Hub repos, log in once or set HF_TOKEN as a Colab secret; never paste tokens into code.

4

Does the adapter change anything?

First sanity check: ask the same question with and without the adapter. The base Gemma answers conversationally with a long categorized markdown list; the fine-tune, trained on compact Q&A, answers briefly and ends by recommending a clinician. Identical answers usually mean the adapter did not load (on Colab, delete the model, garbage-collect and reload); gibberish usually means a tokenizer or chat-template mismatch.

5

Beyond eyeballing

A fine-tune that shines on five hand-picked prompts can fail on the sixth, which is how many die in production. The book climbs a ladder of evaluations, cheapest first. Most serious projects use all four.

6

Reading perplexity

Perplexity is exp(loss): how surprised the model is by the right answer. Synthetic validation data shares the teacher's style and flatters the score, so the book also tests on 100 questions built from a different source (MedQA). Results: base model 27.4, fine-tuned 8.4 on the unseen set (about 69% lower), versus 2.76 on synthetic validation (exp of 1.016). The ratio between unseen and validation perplexity is the health check:

Caveats: the simple scorer predicts the user's turn too, which inflates perplexity; scores depend on the tokenizer; and low perplexity says nothing about whether answers are better.

7

LLM-as-a-judge

To ask "which answer is better", show a strong model the question, a trusted reference answer and two candidate answers, and have it reply A, B or TIE with one sentence of reasoning. The book's fine-tune won about 73% against the base. Judges have biases: they favor verbose answers, their own style, and often a position. Simulate 100 judgments with a judge that leans toward answer A:

Judge hygieneRandomize positions; use a judge stronger than the model under test (a 4B judging a 4B teaches little); always supply reference answers (expert-written first, then established datasets, then reviewed strong-model answers); repeat runs to smooth noise; and prefer private data the judge cannot have seen.
8

Domain benchmarks and pitfalls

Real projects need tests from domain experts: closed lists you can score by recall (the symptoms of X), open questions judged against golden answers, safety prompts where the right answer is to redirect to a professional, and general-knowledge checks to confirm the fine-tune did not erode what the base knew. QLoRA at inferenceYou can serve the adapter on a 4-bit base too: Gemma 4 E4B drops from about 16 GB to 6 to 8 GB. You cannot merge full-precision deltas into 4-bit weights, so the adapter stays attached (which keeps hot-swapping possible). Precision is now a deployment choice, so evaluate in the exact configuration you ship: rerun the canary prompts and perplexity on the 4-bit base.
