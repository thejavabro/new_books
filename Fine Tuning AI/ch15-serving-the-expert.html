A file on disk is not a product

Your 4.5 GB GGUF is what the whole book has been building toward, but nothing can call it until a process loads it and listens for requests. A serving stack's job sounds simple: keep the model in memory and turn requests into responses quickly, correctly, and without falling over. The difficulty is under load: weights, a growing KV cache and overlapping requests. The two ends of the spectrum pull in opposite directions.

Both stacks speak the same OpenAI-compatible API, so you can prototype on Ollama on your desktop and deploy on vLLM without changing client code. The same principles apply to the diffusion models from Chapters 12 and 13; only the request shape changes (prompt in, image bytes out).

2

Ollama: GGUF to a local endpoint

A Modelfile is like a Dockerfile for a model: one shareable file that reproduces the same setup on any machine. Tap a line.

ollama create medical-gemma -f Modelfile, then ollama list and ollama run medical-gemma "…". You get a /v1 endpoint at http://localhost:11434. On a Mac mini M4 the book's model produces tokens faster than you can read them.

vLLM: built for throughput

  
vllm serve ./medical-gemma-merged --served-model-name medical-gemma --port 8000 --max-model-len 8192 --gpu-memory-utilization 0.90 --dtype bfloat16 starts an OpenAI-compatible server. vLLM reads the merged bf16 Hugging Face directory, or a GPU-friendly quant (GPTQ, or QAT w4a16), not the GGUF. Many experts from one base

  
With --enable-lora --lora-modules name=path …, vLLM keeps one base in GPU memory and applies the named adapter per request. 7
The future is specialized

  
The book's path: from the API wall, through the internals of transformers, data work, LoRA and QLoRA, evaluation, DPO, vision, then diffusion, where the same playbook applied, and finally compression and serving. The quiet lesson is that fine-tuning is a general skill, not a trick for language models. The next era is less one model that knows everything and more a swarm of small, private specialists: a hospital's protocols, a company's codebase, an illustrator's style. Each is cheap to retrain when the world changes. Pick a domain you know better than any web crawl does. Gather the data, train, evaluate, compress, serve.
