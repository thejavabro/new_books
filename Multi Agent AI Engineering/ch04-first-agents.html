General background, not from the missing chapterThe four strategies below are widely published techniques named in the chapter's headings. These short descriptions are the companion's own and may not match how the book presents or compares them.

A minimal observe, think, act loop (illustrative)

def run(goal, tools, llm, max_steps=8):
    history = [{"role": "user", "content": goal}]
    for step in range(max_steps):          # budget = stopping rule
        reply = llm(history, tools=tools)      # think
        if reply.tool_call is None:
            return reply.text                  # goal met
        result = tools.run(reply.tool_call)    # act (runtime executes)
        history += [reply.msg, result.msg]     # observe
    return "stopped: step budget exhausted"
