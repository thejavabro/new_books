# Microservices Patterns, Drawn Out

An interactive visual companion to *Microservices Patterns: With examples in Java* by Chris Richardson (Manning, 2019). It has one self-contained HTML page per chapter, plus an index with a pattern finder that lists all 44 patterns.

## How to open

Open `index.html` in any modern browser. Every page is a single file with its CSS and JavaScript built in, and pages link to each other by relative paths, so the folder works offline. With a connection, the pages use Google Fonts; without one they fall back to system fonts. There is a light/dark theme toggle in each page header, and the pages work at phone width.

## About the content

The explanations, code snippets, diagrams and simulations are original summaries written for this companion. Nothing is copied from the book's text, figures or listings, apart from short names of patterns, classes and terms. Numbers in the simulations are illustrative only.

Not included: the front matter (preface, acknowledgments, about this book), the index, and the lists of figures, tables and listings.

## Source completeness

All 13 chapters in the source PDF (691 pages) are present and readable. Every section heading in the table of contents appears in the body text. No chapters or pages were missing, blank or replaced by placeholders.
