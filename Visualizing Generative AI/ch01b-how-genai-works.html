How GenAI Paints, Writes and Sings

An image model learns to remove noise. A text model learns to guess the next token. Both are trained on mountains of unlabeled data, and both are steered by text. Here is the machinery, one idea at a time.

1

Painting by removing noise

Image generation has a data problem. A classifier outputs one label per photo; a generator outputs a million pixel values per image, so learning it the supervised way would need impossibly many labeled examples. Conditional diffusion sidesteps this with four ideas:

Forward: add noise. Backward: learn to remove it.

a 64 × 48 toy image

Slide to add noise in small steps. Each small step is easy to reverse; chaining many reversals turns pure noise into a picture.

2

Writing one token at a time

A text model is trained on billions of sentences to answer one question: given these N tokens, what comes next? That training corpus size gives large language models their name. To write a paragraph, the model predicts, picks, appends and repeats. Picking the single most likely word every time gives robotic, repetitive text, so the model throws a dart at a board where each word's area matches its probability. That is why the same question can get different answers.

3

Tokens, not words

No finite vocabulary holds every name, product code and number. So models split text into tokens: common words stay whole, rare words break into short pieces of one or two characters. A fixed token list can then represent any text. The cost: names, citations and numbers are spread over many tokens, which makes them harder for the model to get right. Type anything to see a toy tokenizer at work.

4

Transformers: position plus attention

Modern GenAI rests on the transformer, introduced for translation in the 2017 paper "Attention Is All You Need". Earlier recurrent networks read words one by one with a fading memory, and translation suffered when word order or gender differed between languages. Transformers add two ideas: positional embeddings (each token also carries its relative position) and attention (when producing each output word, the model weighs every input word differently). Training text for LLMs comes from public sources such as Common Crawl, Wikipedia, patents and book collections, and increasingly from licensing deals with sites such as Reddit and Stack Overflow.

5

From next-word predictor to helpful assistant

A raw decoder continues text with whatever is statistically likely. To make it follow instructions, model trainers prefix thousands of example inputs with a task description ("Summarize the following paragraph in two sentences:") and train on the desired outputs. This is supervised fine-tuning, also called prefix or instruction tuning. Google's T5 (2020) did it for a few tasks; by GPT-3 the model generalized to tasks it was never explicitly shown.

Then comes human feedback. The model writes two answers, a person picks the better one, and after 100,000 to 1,000,000 such choices a reward model learns to predict human preference. Be the rater:

Prompt

RLHF and DPOOpenAI used reinforcement learning with a separate reward model. In 2023, Stanford researchers showed with direct preference optimization (DPO) that the same preference data can tune the model directly, no reinforcement learning needed. That made preference tuning cheap enough for open models to catch up.
6

You are talking to a product, not a bare model

ChatGPT, Gemini and Claude on the web are products architected around a foundational model. The model alone only generates text from its training. Click each part the product adds; as a developer calling a raw model, you build these yourself.
