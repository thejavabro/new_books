Use Cases: Customer Support and Code

Two areas where evidence of real value has piled up fastest: the contact center and the code editor. Both show that GenAI works best when it is carefully built around people.

1

What enterprise buyers look for

A common criticism is that GenAI is all hype. The chapter answers with deployments that have measurable results. In consumer products, AI wins by cutting friction, improving accuracy, scaling or adding efficiency. In business-to-business software, the buyer (not just the user) must be convinced, and buyers mostly look for two of those: scale (nontechnical people can do what used to need technical people) and efficiency (manual work becomes automatic).

The authors push furtherScale and efficiency are a short-sighted lens. Agentic systems (chapter 4) can also cut the friction of using complex enterprise software and raise the accuracy of enterprise tasks. And because nondeterminism, hallucination, toxicity and bias have not gone away, start with well-defined problems that have clear success metrics, not a broad rollout.

3

Call deflection, old and new

Answering calls automatically is not new: in 2018 Marks & Spencer cut calls to stores by 50%. But the old pipeline was slow and brittle, and engineers had to anticipate every utterance (one newspaper's bot famously made it impossible to unsubscribe). GenAI agents understand unforeseen phrasing, stream in real time, let callers interrupt, call backend APIs, and hand over to a human with a summary when they cannot finish.

4

From sampling calls to reading all of them

Managers used to judge agents from the few calls they had time to hear. GenAI scores every transcript for KPIs and leading indicators (proper greeting, script adherence, upsell attempts), in real time or in batch, sliced by agent and call type. Each square below is a call; amber ones contain a compliance problem.

Read across all calls, the same analysis feeds a product insights flywheel: spot patterns in complaints, rank them by impact and frequency, fix the product, then confirm the complaints go away. Analysis also reveals which intents can be automated next.

5

A copilot for the human agent

Agents juggle many systems, deep product knowledge and difficult customers. Agent-assist tools listen along and offer suggestions, knowledge snippets, next best actions and draft replies, then do the after-call chores: notes, CRM updates, routing. Step through a call.

The flip sidePop-ups can distract agents mid-conversation, push them away from their own voice, or feel pointless to experienced staff. Vendors say newer agents value the safety net most.
6

Coding assistants: read the claims carefully

Software engineering is the second area with strong evidence. In one Accenture study, 67% of respondents used GitHub Copilot at least five days a week, and both authors find they stay "in the flow" longer with an assistant. But the headline numbers deserve a grain of salt. Tap each claim.

A two-year Harvard Business School study of open source developers found that those using Copilot spent more time on core coding and less on project management, worked more autonomously and explored more, and the effect was strongest for less experienced developers, a possible flattening of hierarchies.

7

How AI code generation and review are built

Code suits next-token prediction unusually well: there are fewer valid ways to write a function than to phrase a sentence, syntax is strict, idioms repeat, and huge amounts of open source code exist to learn from. Commercial tools stack four layers. Click one.

Enterprises want models tuned on their own code but fear it training someone else's model. Specialists such as Tabnine fine-tune open models on a customer's codebase in isolation, with on-premises options and a personalization service between model and developer; studies they cite report about 17.5% productivity gains.
