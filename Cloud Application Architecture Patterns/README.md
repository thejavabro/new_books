# Cloud Application Architecture Patterns: visual companion

Interactive, self-contained HTML pages that walk through *Cloud Application Architecture Patterns: Designing, Building, and Modernizing for the Cloud* by Kyle Brown, Bobby Woolf and Joseph Yoder (O'Reilly, 2025), one page per chapter (Chapter 7 is split over two pages).

Each page has inline SVG diagrams, small simulations and step-throughs, and a short quiz at the end. Pages work in light and dark themes (follows your system setting; there is also a toggle at the top) and at phone width.

## How to open

Open `index.html` in any modern browser. Everything is in the HTML files; no server and no install needed. The pages work offline: the only external resource is a Google Fonts stylesheet, and system fonts are used if it cannot load.

## About the content

The explanations, examples, code snippets and drawings are original summaries written for this companion. They are not text or figures from the book, and only short phrases (such as pattern names and problem questions, paraphrased) are taken from it. Simulations are illustrative toy models, not data from the book. Front matter and the index were skipped; the book's closing chapter is summarized at the end of the Chapter 10 page.
