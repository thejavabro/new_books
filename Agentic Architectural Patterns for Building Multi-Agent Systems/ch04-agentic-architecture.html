How agents interact

Agents coordinate either by talking to each other directly or by changing a shared environment that others watch, the way ants leave trails (stigmergy).

Recap on one page

Agents ≠ LLMsAn LLM is stateless and passive; a workflow is fixed; an agent is goal-directed, stateful and adaptive.
Anatomy → layersSense = input layer, Reason/Plan = cognition, Act = tools, Memory = state, Coordinate = A2A.
TeamsSpecialists coordinated by explicit, auditable task delegation; edge cases go to deliberation or humans.
Data contextStructured, unstructured, vectors, graphs, real-time streams and actuators.
InteractionDirect messages or indirect stigmergy, on top of function calling, MCP and A2A.
