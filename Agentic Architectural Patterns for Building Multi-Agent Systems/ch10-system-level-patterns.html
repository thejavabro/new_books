System-Level Patterns for Production Readiness

Some patterns live in no single agent. They are the environment every agent runs in: a front door that checks identity, a bus that carries events, a directory of capabilities, and a referee that enforces the rules in real time.

Event-Driven Reactivity: stop polling

A support agent can ask "any new tickets?" every few seconds, or it can subscribe to a topic and be woken when one arrives. Run both for a quiet minute with three tickets.

3

Agent Authentication and Authorization

Agents are first-class identities. Each request carries a short-lived signed token (authentication: who are you?), and the gateway checks the role's permissions (authorization: what may you do?). Choose who asks for what.

Real-Time Compliance Monitoring

  
Authorization asks can this agent read patient records? Compliance asks may it read this patient's record for this purpose right now? A policy engine adjudicates every intercepted action before it happens. Pick a patient and a purpose.

Tool and Agent Registry: the yellow pages

  
Agents should not hard-code who to call. They register capabilities and discover others by meaning. Register a new agent, then search.
