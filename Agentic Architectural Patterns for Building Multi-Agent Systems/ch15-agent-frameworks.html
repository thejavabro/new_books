Agent Frameworks: The Loan System in CrewAI and LangGraph

Frameworks save you from rebuilding planners, state managers and tool dispatchers. Each has a different mental model: ADK treats an agent as a production component, CrewAI as a team member, LangGraph as a node in a state machine. The patterns stay the same.

Three mental models for the same job

All three use an LLM as the reasoning engine, are built around tool calling, and target multi-step goals. They differ in their core abstraction. Switch between them.

LangGraph's superpower: state you can inspect

A typed state object is passed to every node; each node returns updates. Step through the happy path and watch it fill in. CrewAI passes outputs implicitly as task context; ADK keeps state in its managed session.
