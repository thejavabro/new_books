Use Case: A Single Agent for Loan Processing

Theory meets a real workflow. One agent, guided by a Fractal Chain-of-Thought prompt and four tools, processes loan applications end to end, and then shows exactly where a monolith starts to crack.

1

The challenge: a high-stakes, five-stage workflow

Loan origination is a chain of stages, each with its own data, rules and ways to fail. Rigid scripts break on messy inputs; the work needs planning, exception handling and an audit trail. Pick a stage.

2

Why a plain prompt drifts: lost in the middle

In a long, multi-step run, constraints stated once at the start get buried, so the agent slowly drifts from its mission. FCoT counters this by re-reading the contract on every iteration. Grow the context and compare.

3

FCoT part 1: the instruction contract

The contract is the agent's immutable source of truth. Tap a clause to see which pattern it implements.

4

FCoT part 2: the recursive loop (N = 3)

Three iterations, each with RECAP → REASON → VERIFY. "N = 3" is an instruction to the model in plain English, not a code parameter; the code only sets the thinking budget (how many tokens), while the prompt sets the algorithm (how to think).

5

The monolithic agent: one brain, one toolbelt

The single agent is built from three parts: the FCoT reasoning core, session state handled by the runner, and a toolbelt of four functions. Hover or tap a tool.

The four tools return mock data here; in production the same signatures would wrap real document systems, bureau APIs or MCP services, ideally with strongly typed data contracts (for example, Pydantic models).

6

Run the agent: happy path, rejection and failure

Pick an applicant and a world condition, then process. The log shows thoughts and tool calls, which is what exposing the agent's thinking buys you in observability.

7

Machine learning calculates, the agent explains

A hybrid pattern: a traditional model computes risk and SHAP values (how much each feature pushed the decision); the agent turns them into a justification a customer can understand.

8

Cracks in the foundation: toward a multi-agent design

The monolith works, and is a genuine milestone. Three pressures show where it will strain. Add stages to the workflow and watch the single prompt grow.
