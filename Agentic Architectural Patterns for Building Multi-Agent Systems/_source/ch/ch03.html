Chapter 1 measured an organisation. This second lens measures the architecture: how much an agent reasons, reflects and coordinates. Later chapters say "Level 4" or "Level 6" using this scale.

An agent can be a tiny specialist ("check inventory") or a coarse process owner ("fulfil the order"). Drag the slider to split one onboarding process into finer agents and watch the trade-off.

The onboarding orchestrator delegates compound tasks (KYC, credit check) to specialist sub-agents and does atomic jobs (send the welcome email) with a plain tool. Callbacks fire around every model and tool call, so nothing happens off the record.

RAG fetches relevant, current documents at the moment of the question and puts them in the prompt. Pick a scenario from the chapter and compare the agent with and without it.

Fine-tuning updates weights so knowledge, tool-call formats or a tone become second nature. Full fine-tuning (FFT) updates everything; parameter-efficient fine-tuning (PEFT) freezes the base and trains a small add-on. Toggle to see which weights move.

No training at all: put a few worked examples in the prompt and the model copies the pattern. Build the product-feedback analyser prompt and watch the output format firm up as you add examples.
