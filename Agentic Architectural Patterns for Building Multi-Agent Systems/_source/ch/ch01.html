The shift in one line. A chatbot returns words. An agent returns an outcome, and it has to be trusted to change real systems on your behalf. Everything else in this book is about earning that trust.

Business uses fall into two families. Horizontal applications help every department (writing, search, summarising, coding help). Vertical applications are built for one industry's data, rules and vocabulary, such as claims triage in insurance or adverse-event review in pharma.

An agent is an LLM given a body. Click each part to see what it does. The orange dot shows one trip around the loop: sense the world, reason, plan, act, remember, and coordinate with others when the job needs a team.

Organisations climb to agents one rung at a time. Each rung rests on the ones below it: you cannot trust an autonomous agent if you never built clean data, retrieval and evaluation. Pick a rung to see what you build there and how big the blast radius is when it goes wrong.

Avoid architectural overreach. A team that has just shipped a retrieval chatbot (level 2) and asks for a fully autonomous campaign manager is skipping grounding and evaluation. The better next step is a narrow single agent that drafts work for a human to approve.
