The agent's core loop is perceive → reason → act. Memory and knowledge sit beside the loop as a resource. Click a layer to see which pattern strengthens it.

One LLM, a goal in a prompt, a set of tools, and a reasoning loop (ReAct or FCoT) that decides which tool to call next. Simple to build and debug, and the benchmark every fancier design must beat. Its limit shows when you give it too many tools.

A stateful loan assistant remembers what you told it. Short-term memory is the recent conversation (a sliding window or summary). Long-term memory is a store of facts and preferences across sessions. Toggle them and replay the chat.

The agent looks things up before it answers. Pick a question to see indexing, retrieval by meaning, augmentation and generation in action. Adjust how many chunks to retrieve.

Instead of answering in one pass, the agent anchors its objective, reasons step by step, critiques its own draft against the rules, and revises. Step through a loan decision where the first draft is wrong.

Many workflows run on images: scanned forms, screenshots, photos of damage. Two ways to give an agent eyes. Pick one and process the scanned loan form.
