# Latency, Drawn Out: a visual companion

An interactive, chapter-by-chapter companion to *Latency: Reduce delay in software systems* by Pekka Enberg (Manning). Each chapter has its own page with diagrams, step-through animations, small simulations, a short quiz and a recap.

## How to open it

Unzip the folder and open `index.html` in any modern browser. Everything works offline: the pages are self-contained HTML with no external scripts. Google Fonts load when you are online, and system fonts are used otherwise. A Theme button in each page header switches between auto, light and dark.

## About the content

All explanations, examples, code snippets and drawings are original summaries written for this companion. They are not text or figures from the book. Simulations use illustrative numbers unless they are labelled as the book's benchmark results. Read the book for the full treatment.
