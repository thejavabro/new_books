# The Effective Software Engineer — Visual Guide

An interactive, chapter-by-chapter companion to *The Effective Software Engineer* by Addy Osmani (O'Reilly, 2026). Every page explains one chapter with diagrams, animations, step-throughs, sliders, small games and a short quiz at the end.

## How to open

Open `index.html` in any modern browser; it works offline. Each page is a single self-contained HTML file and links to the others with relative paths, so keep the files together in one folder. Pages adapt to phone screens and have a light/dark theme button (it follows your system setting by default).

## A note on content

The explanations, examples, code snippets and visuals are original summaries written for this guide. They are not text from the book; at most a few short phrases are quoted. Numeric charts and simulations are illustrative toy models, not data from the book, unless a figure is explicitly attributed. The book's index is not reproduced. To get the full argument, read the book.

`_source/` (present in the project folder only) holds the build script and page sources: `python3 build.py <outdir>`.
