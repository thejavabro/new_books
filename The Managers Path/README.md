# The Manager's Path: visual companion

Interactive, one-page-per-chapter study notes with diagrams, animations, calculators, sorting games and quick checks.

## Use it
- Unzip into `C:\repo\new_books\` (you'll get a `The Managers Path` folder).
- Open `index.html` in any browser. No install or build step; every page is self-contained.
- Fonts load from Google Fonts; offline, pages fall back to system fonts and still work.
