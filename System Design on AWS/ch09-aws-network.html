Where AWS lives

Everything starts with an AWS account (ideally several, organised under AWS Organizations: one per environment or team). Resources then live somewhere physical. Click each level, from largest to closest to the user.

2

IP addresses, CIDR and subnets

A VPC is defined by a private IPv4 range written in CIDR notation: 10.0.0.0/16 means the first 16 bits name the network and the remaining 16 address hosts. Classful addressing (classes A, B, C) wasted space; CIDR and variable-length masks let you cut ranges to size. IPv6 (128 bits) is the long-term fix for address exhaustion. In every AWS subnet, 5 addresses are reserved: the first four and the last.

3

Inside a VPC: subnets, gateways and route tables

A subnet is public if its route table sends 0.0.0.0/0 to an internet gateway (IGW). Instances in private subnets reach the internet only outward, through a NAT gateway that sits in a public subnet. Every route table also has a local route for traffic inside the VPC. Trace a packet.

4

Security groups and network ACLs

Route tables decide where traffic goes; two filters decide whether it may. Security groups attach to instances (network interfaces), allow-only, and are stateful: a reply to allowed traffic is automatically allowed. Network ACLs attach to subnets, have numbered allow and deny rules evaluated in order, and are stateless: return traffic needs its own rule, usually for ephemeral ports 1024–65535. Test a web request.

5

Connecting VPCs: peering, Transit Gateway, PrivateLink

VPC peering links two VPCs privately, one to one, and is not transitive: if A peers with B and B with C, A still cannot reach C. With many VPCs the mesh explodes. Transit Gateway is a regional hub: each VPC (and VPN or Direct Connect) attaches once. PrivateLink exposes one service, not a whole network, to consumers in other VPCs through an interface endpoint.

The front door: Route 53, ELB, API Gateway, CloudFront

Route 53 is AWS's DNS: domain registration, hosted zones of records (A, AAAA, CNAME, MX, TXT and free alias records pointing at AWS resources), health checks and routing policies, served over anycast. Pick a policy and send a query from a user.
