AWS Messaging, Orchestration and Monitoring

The glue of cloud systems: streams and queues that decouple services, workflows that coordinate them, and the monitoring and access control that keep them honest.

Streaming: Amazon MSK and Kinesis Data Streams

Both carry ordered, replayable streams of events. Amazon MSK is managed Apache Kafka (provisioned brokers or serverless): pick it when you already speak Kafka, need exactly-once semantics, long retention or the Kafka ecosystem. Kinesis Data Streams is AWS-native: capacity is counted in shards (or on-demand mode), each taking up to 1 MB/s or 1,000 records/s in and giving 2 MB/s out, shared by all consumers unless they use enhanced fan-out (a dedicated 2 MB/s each, push delivery around 70 ms). Size a stream.

SQS: standard and FIFO queues

SQS decouples producers from consumers. A consumer receives a message, which then becomes invisible for the visibility timeout; it must delete it after processing, or the message reappears for someone else. After too many failed receives, a redrive policy moves it to a dead-letter queue. Messages are kept up to 14 days and can be up to 256 KB (store bigger payloads in S3 and send a pointer). 3

SNS: push to many, with filters

SNS is pub/sub: publish once to a topic and it pushes copies to every subscriber (SQS queues, Lambda, HTTP endpoints, email, SMS, mobile push). Filter policies on each subscription let a subscriber receive only messages whose attributes match, so filtering logic leaves your code. The classic pattern is SNS to several SQS queues: fan-out plus buffering. Publish an offer.

4

Step Functions: workflows as state machines

Step Functions runs workflows written in the Amazon States Language: Task (call Lambda or one of hundreds of AWS APIs directly), Choice, Parallel (fixed branches), Map (the same steps over each item of a list, inline or distributed over millions of S3 objects), Wait, Pass, Succeed and Fail. Each state can declare Retry with backoff and Catch to route errors. Step through a food order.

CloudWatch: logs, metrics and alarms

CloudWatch collects logs into log groups and streams (search them with Logs Insights, set retention, export to S3), metrics (time-ordered data points in namespaces with dimensions, summarized by statistics such as average, p99 and max) and alarms. An alarm watches one metric or a math expression and changes state when M out of N datapoints breach a threshold, then acts: notify via SNS, scale an Auto Scaling group, reboot an instance. Tune this latency alarm.

CloudWatch Events, now Amazon EventBridge, routes state changes ("instance stopped", "object created", your own app events) through rules with event-pattern filters to targets such as Lambda, SQS or Step Functions, and can also run schedules. Composite alarms combine alarms to cut noise.

6

IAM: who can do what

IAM has users (long-term credentials, increasingly replaced by federated sign-in), groups of users, and roles that people, services and other accounts assume for short-lived credentials. Permissions are JSON policies: Effect, Action, Resource, optional Condition. Evaluation is simple: anything not allowed is denied, an explicit Deny beats any Allow. Lock the root user away with MFA. Toggle policy statements and test a request.

7

Cognito and AppSync

Authentication (AuthN) proves who you are; authorization (AuthZ) decides what you may do. Cognito handles both for app users. A user pool is a user directory with sign-up, sign-in (hosted UI, social and SAML identity providers, MFA) that issues JWTs. An identity pool swaps a token for temporary AWS credentials tied to an IAM role, for example to upload a photo directly to S3. Lambda triggers customise each step.

AWS AppSyncManaged GraphQL (and real-time pub/sub) APIs. Resolvers connect each field of the schema to a data source (DynamoDB, Aurora, Lambda, HTTP, OpenSearch), so one query can gather restaurant details and menu items from different stores. Merged APIs combine several teams' schemas behind one endpoint; subscriptions push updates over WebSockets; Cognito, IAM and WAF secure it.
