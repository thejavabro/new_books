# Head First Software Architecture: visual companion

Interactive, illustrated study pages for every chapter of *Head First Software Architecture* (Gandhi, Richards, Ford; O'Reilly 2024).
Explanations and drawings are original summaries, not text from the book.

Open `index.html` in any browser. Everything runs offline except the web fonts (the pages fall back to system fonts without internet).
Works as-is from a local folder, a GitHub repo clone, or GitHub Pages.
