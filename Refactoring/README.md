# Refactoring: visual companion

Interactive study notes for *Refactoring: Improving the Design of Existing Code* (2nd edition) by Martin Fowler, with contributions by Kent Beck (Addison-Wesley, 2018). There is one page per chapter, with animated before-and-after code, diagrams, small simulations and a quick check at the end of each page.

## How to open it
- Open `index.html` in any browser (double-click it). There is nothing to install and no build step.
- Every page is self-contained and works offline. Fonts load from Google Fonts when you are online; offline, the pages use system fonts.
- Light and dark themes follow your system setting. The "Theme" button switches between them.

8. Moving Features: `ch08-moving-features.html`
9. Organizing Data: `ch09-organizing-data.html`
10. Simplifying Conditional Logic: `ch10-conditional-logic.html`
11. Refactoring APIs: `ch11-refactoring-apis.html`
12. Dealing with Inheritance: `ch12-inheritance.html`

The catalog chapters (6 to 12) group all 61 refactorings by chapter. Each one has a card with a short example. Press "Next step" or "Play" to watch the code change: lines that are kept move to their new position, new lines appear in green, and removed lines are struck through in red. The index page has a search box that finds any refactoring by name.

The bibliography and the book's index are not covered.

## A note on content
All explanations, code snippets, diagrams and quizzes are original summaries written for this companion. They are not text from the book. Page numbers such as "p. 106" follow the book's own cross-reference style, so you can find the full treatment there.
