# Agentic AI for Engineers: visual companion

Interactive, illustrated learning pages for *Agentic AI for Engineers: Architecting Goal-Driven Systems* by Dhivya Nagasubramanian (Apress, 2026). There is one self-contained HTML page per chapter (14 in all) and an index.

## Use it
- Open `index.html` in any browser (double-click it). There is nothing to install and no build step.
- Keep all the files together in one folder, for example `C:\repo\new_books\Agentic AI for Engineers\`. The pages link to each other by relative path.
- Fonts load from Google Fonts. Offline, the pages fall back to system fonts and still work.

## What's inside
- Diagrams, animations, step-through walkthroughs, simulations with sliders, small games and quick-check quizzes on every page.
- Light and dark themes, and layouts that work on a phone.
