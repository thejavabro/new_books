Tools and Frameworks

A clever prompt is not a system. Agent frameworks supply the rest: tools, memory, orchestration, observability and guardrails. This chapter maps the layers, shows how to build tools that outlive any one framework, and compares the four orchestrators you will meet most often.

The agentic stack, layer by layer

Function first, wrappers second

Write one small, typed function that does one job and returns structured data. Then add thin adapters for each runtime. The business logic never moves; only the wrapper changes. Switch frameworks and notice the core stays highlighted and identical.

6

One task, four orchestration philosophies

Task: "research a competitor and write a one-page brief". LangChain chains components and lets an agent pick tools. LangGraph is a state machine of nodes, edges and one typed state. CrewAI is a team of roles passing tasks. AutoGen is a group chat of agents with tools. Run each.

7

Why explicit state matters: crash and resume

A long approval workflow dies halfway (restart, timeout, outage). With a durable checkpoint after every node, it resumes exactly where it stopped, even after pausing for a human. Without one, it starts over and may repeat side effects.

Managed cloud agent platforms

The big clouds now offer orchestration, tools, memory and guardrails as managed services. Less plumbing, less customisation, more lock-in. Compare one dimension at a time.

10

Visual builders: a shared design surface

Low-code canvases let product, design and compliance people see the flow as it runs, and most export runnable code, so the prototype becomes scaffolding. Add blocks to sketch a flow, then export.
