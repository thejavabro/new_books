Build Your First AI Agent

Time to build. The example is a research assistant that finds papers, summarises them, critiques its own work, gets a confidence score from a judge, and asks a human before publishing. It grows the way real agents grow: simple, then modular, constrained, self-evaluating and finally supervised.

Grow it in five stages

Skip the "general agent" trap. Pick one narrow, concrete job, get it working, then add one layer at a time. Step through and watch the pipeline grow.

The backstory is not decoration

Same task, same model, same search results. Only the backstory changes. Compare the openings of the answer.

4

Be precise about the expected output

The expected output is the contract the next agent depends on. Run the research task five times with each spec and see how consistent the output shape is.

5

Run the whole pipeline

Tune the knobs the chapter introduces: the critic's quality bar, the retry cap, the judge's confidence bar, and whether a human reviews. Then run "large language model alignment" through it.

6

Copy editor vs editor in chief

The critic scores drafts during the loop and feeds back what to fix. The judge looks only at the final result and gives a confidence score that decides what happens next. Different stages catch different problems.

CriticInside the loopScores accuracy, clarity, completeness 1–5 per summary, writes specific feedback, sends drafts back.
JudgeAt the gateReads the finished piece, checks facts against sources, returns a confidence and a recommendation: publish, revise, or escalate.
7

Guardrails are assertions for agents

Each check sits between two stages and fails fast with a precise reason. They prevent bad output, correct it to a standard, and keep the run auditable. Test three outputs from the summariser.

8

Know your costs before you scale

Develop on a small cheap model, switch up only when the pipeline works, and cap loops. A missing cap can turn a few cents into a real invoice. Costs below are illustrative.

9

The final blog post claims a paper from 2031. Turn on verbose output and inspect each stage's intermediate result. Click the stage where it went wrong.
