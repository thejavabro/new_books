# Seeking SRE: visual companion

An interactive, chapter-by-chapter companion to *Seeking SRE: Conversations About Running Production Systems at Scale* (curated and edited by David N. Blank-Edelman, O'Reilly, 2018). The book is a collection of contributed chapters; short chapters are grouped so each page is substantial (17 pages covering 33 chapters).

Each page has diagrams, small simulations, flip cards and a short quiz, works offline, supports light and dark themes, and is readable on a phone.

## How to open

Unzip, then open `index.html` in any modern browser. All links are relative; no server or internet connection is needed (fonts fall back to system fonts when offline).

## About the content

All explanations, examples, simulations and drawings are original summaries written for this companion. They are not text from the book, and numbers in simulations are illustrative unless the page says otherwise. Front matter, the preface and the book's index are folded into `index.html` rather than given their own pages.
