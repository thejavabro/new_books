Because it makes sense, and now we can

Amaro runs thousands of instances moving petabytes of data, with logs and metrics to match. Alerts, in some amount, will get out of hand if nobody checks them. Machine learning promises to augment human understanding of complex interactions and large datasets, preventing toil and freeing people for creative work. The problems he would like it to solve:

Why now?Deployments get faster and humans can react only so fast. Two things changed: there is now enough data from big-data efforts, and cheap GPUs to train on it. And deep learning turned out to be surprisingly simple at its core. Historically, AI progress came from search algorithms in games (minimax for tic-tac-toe and chess); Go was too large to search, which is where learned evaluation took over.
2

A neuron is just a function

An artificial neuron multiplies each input by a weight, sums them with a bias, and passes the result through an activation function such as a sigmoid, which squashes it between 0 and 1. A network is many of these in layers. Here, one neuron scores whether a host looks unhealthy from two normalized signals.

output = sigmoid(w₁x₁ + w₂x₂ + b)
3

Learning is just reducing the loss

The chapter's first TensorFlow example trains a single neuron: input 1.0, starting weight 0.8, desired output 0. A loss function measures how wrong the output is (here, squared error), and gradient descent nudges the weight downhill a little each step. Choose a learning rate and train.

// a tiny version of the same idea, in plain JavaScript
let w = 0.8; const x = 1.0, target = 0.0, lr = 0.025;
for (let step = 0; step < 100; step++) {
  const y = w * x;                 // forward pass
  const grad = 2 * (y - target) * x; // d(loss)/dw for loss = (y - target)^2
  w -= lr * grad;                  // move downhill
}

TensorFlow builds a graph of operations first and only computes when a session runs it; TensorBoard then plots the loss and the graph. Keras wraps TensorFlow with a simpler API. Other libraries Amaro tried: Caffe, scikit-learn, Theano, Torch.

Forecasting and anomalies in a time series

The most useful ML for SRE, in Amaro's view, is on time series: a signal measured at regular steps, like requests per hour. Two wishes: forecast load a few hours ahead, and detect anomalies to trigger automation. Future values are estimated from past values of the same series, so the choice of time step matters. This demo uses a simple seasonal forecaster (not a neural network) to show the idea: learn the daily pattern, predict, and flag points far from the prediction.

6

Where it already pays off

Areas where AI is having an impact in IT operations: log analysis, capacity planning, infrastructure scaling, cost management, performance tuning, energy efficiency and security. The headline example: DeepMind trained an ensemble of neural networks on historical data-center sensor readings (temperatures, power, pump speeds, setpoints) to predict future power usage effectiveness, and used it to steer Google's cooling, cutting cooling energy by up to 40%. Simpler methods count too: naive Bayes classifiers for routing tickets or spotting spam.
