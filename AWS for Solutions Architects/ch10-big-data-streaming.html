Big Data and Streaming Data Processing

Data is capital. This chapter covers the services that collect, transform and process it: in large batches with EMR and Glue, or as it arrives with Kinesis and Kafka.

1

Data is capital: why process it in the cloud

Businesses now hold terabytes or petabytes of data and want insight from it fast. Running Hadoop or Spark clusters on-premises means buying for peak, idling the rest of the time, and keeping storage and compute stuck together. In the cloud you keep data cheaply in S3, spin up exactly the compute a job needs, and shut it down when the job ends.

2

Amazon EMR: managed Hadoop and Spark

EMR runs open-source engines (Spark, Hive, Presto, HBase, Flink and more) on a managed cluster that reads data straight from S3 through EMRFS, so many clusters can share one data lake. A cluster has three node types. Tap one, then toggle Spot for task nodes.

Persistent or transient?A persistent cluster stays up for interactive queries and notebooks. A transient cluster starts for a batch job, writes results to S3 and terminates, so you pay only while it works. Separating storage (S3) from compute is what makes transient clusters possible.
More EMREMR Studio is a managed notebook IDE for data engineers and scientists. EMR also runs on EKS and as EMR Serverless. Security configurations turn on encryption at rest and in transit, plus Kerberos and Lake Formation integration.
3

AWS Glue: serverless ETL and the Data Catalog

Glue is serverless data integration. Its Data Catalog is the metadata store (databases, tables, schemas, partitions, with schema version history) that Athena, EMR and Redshift Spectrum all share. Crawlers run classifiers (built-in for JSON, CSV, Parquet, ORC, Avro, XML and so on, or your own grok patterns) to infer schemas. Jobs run generated or hand-written Spark code. Step through a pipeline.

4

Partitions and predicate pushdown

Write data into S3 folders named by a low-cardinality column, such as s3://employees/year=2020/month=01/. Then a query that filters on that column reads only the matching folders: partition pruning, or predicate pushdown. Pick a filter and see how much data is read.

5

Streaming with Amazon Kinesis

Batch results arrive too late to stop a fraudulent payment. Streaming services process data as it arrives. Kinesis Data Streams stores records in shards. The book compares each shard to a water pipe: each takes in 1 MB/s or 1,000 records/s, and serves 2 MB/s to readers. Size your stream.

6

Amazon MSK, and choosing between the two

Amazon MSK runs Apache Kafka for you: brokers across AZs, ZooKeeper (or KRaft), patching and monitoring, using the native Kafka APIs. MSK Serverless removes cluster sizing altogether, and MirrorMaker replicates between clusters. Keep producers and consumers in agreement on data formats with the Glue Schema Registry.
