AI, ML and the three ways to learn

Machine learning lets a program learn patterns from data instead of following hand-written rules; AI is the wider goal of machines doing tasks that need human-like intelligence. ML comes in three main forms: supervised (learn from labeled examples), unsupervised (find structure in unlabeled data) and reinforcement (an agent learns by trial, error and reward). 5

MLOps: models decay

A model trained on last year's data slowly gets worse as the world changes: drift. MLOps applies DevOps to ML: versioned data and models, automated pipelines (SageMaker Pipelines), a model registry, monitoring (SageMaker Model Monitor) and retraining when quality drops. Let time pass.

6

IoT on AWS

The Internet of Things connects physical devices (thermostats, trucks, factory machines) to the cloud. Devices connect to AWS IoT Core over MQTT with X.509 certificates; the rules engine filters messages with SQL and routes them to other services. Send readings from a freezer sensor.

Rule: SELECT * FROM 'store/+/freezer' WHERE temp > -10

7

Blockchain, quantum and generative AI

A blockchain is a shared ledger: each block stores a hash of the previous one, so changing an old record breaks every link after it. Amazon Managed Blockchain runs Hyperledger Fabric or Ethereum networks so several organizations can share one ledger, for supply-chain tracing, say, without a central authority. (When one organization only needs a tamper-evident log, QLDB from Chapter 7 is simpler.) Edit a block's data.
