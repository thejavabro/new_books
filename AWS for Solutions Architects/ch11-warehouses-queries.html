Data Warehouses, Data Queries, and Visualization

Once data lands, someone has to ask it questions. Redshift is the warehouse, Athena queries files where they sit, and QuickSight turns the answers into dashboards.

1

Amazon Redshift: the cloud data warehouse

Cheap cloud storage means businesses no longer have to throw data away. To analyze it at scale, Redshift started as a PostgreSQL fork with its storage engine rewritten to be columnar and massively parallel. A leader node plans each query and compiles it to code; compute nodes, split into slices, each work on their share of the data. Step through a query.

2

Why columnar storage wins for analytics

An analytical query usually touches a few columns of many rows. A row store must read whole rows; a column store reads only the columns asked for, and similar values in a column compress well. Run the same query against both layouts.

SELECT SUM(amount) FROM sales WHERE region = 'EU'

3

Amazon Athena: SQL on files in S3

Athena is serverless SQL over data where it already sits in S3: logs, clickstreams, IoT readings, transactions. It is built on Presto (now Trino) for queries and Hive for table definitions, and it uses the Glue Data Catalog. There's no cluster: you pay per terabyte scanned (about $5 per TB at the time of writing). So the less you scan, the less you pay. Toggle the optimizations for a 1 TB CSV dataset.

4

Predicate pushdown with min/max statistics

Parquet and ORC store minimum and maximum values for each block. Athena compares the query's filter with those stats and skips blocks that can't match, without reading them. Sorting data by the column you filter on most makes the ranges tighter. Move the filter value.

5

More Athena tuning tips

Federated QueryData rarely lives in one place. Athena connectors (Lambda functions) let one SQL statement join S3 with DynamoDB, Redshift, DocumentDB, CloudWatch Logs, HBase, Redis or any JDBC database, instead of writing ETL to merge them first. You can write custom connectors too.
WorkgroupsSeparate users and teams into workgroups, each with its own query history, output location, encryption key, per-query data limits and cost tracking.
6

Athena or Redshift Spectrum?

Both query S3 with SQL. Athena is standalone, serverless and ad hoc. Redshift Spectrum is part of a Redshift cluster: it lets you join warehouse tables with data still in S3, for example recent transactions in Redshift and older history in S3.

7

Visualizing with QuickSight

QuickSight is serverless BI: no servers, pay per user or per session, from a handful of users to tens of thousands. Its in-memory engine, SPICE, makes dashboards fast; ML Insights flags anomalies and forecasts; Q answers natural-language questions. Pick a question and see which visual suits it.

8

An analytics pipeline end to end

Ingest (Kinesis, DMS, Glue) → store in an S3 data lake → catalog with Glue → query with Athena or load into Redshift → visualize in QuickSight. Each stage scales and bills independently.
