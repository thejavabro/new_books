Networking in AWS

Networking is the first thing you build in AWS and the backbone everything else sits on. Start with the global footprint, then carve out a private network and connect it to the world.

1

Regions, Availability Zones and edges

AWS's footprint nests like Russian dolls. A Region is a geographic area (for example us-east-2, Ohio) built to be isolated from other Regions. Inside each Region are several Availability Zones (AZs): one or more data centers with their own power and cooling, far enough apart to survive a local disaster but joined by fast, redundant, encrypted links. Local Zones put a slice of compute close to big cities (named like us-west-2-lax-1a), Wavelength Zones sit inside 5G carrier networks, and hundreds of edge locations serve CloudFront and Route 53. Tap a layer.

2

Your own network: the VPC

A Virtual Private Cloud is a private network inside one Region that can span its AZs. You give it a CIDR block (an IP range such as 10.0.0.0/16), carve it into subnets per AZ, and attach route tables. A subnet is private by default. It becomes public only when its route table sends 0.0.0.0/0 to an internet gateway. Private subnets reach out through a NAT gateway; admins reach in through a bastion host. Pick a path and trace the packet.

3

Many VPCs: peering mesh or Transit Gateway

VPC peering links two VPCs directly, but peering is not transitive, so a full mesh needs a link between every pair. Transit Gateway is a regional hub: each VPC (and your on-premises network) attaches once. The book notes up to 5,000 attachments per TGW and up to 50 Gbps per VPC attachment. Slide the number of VPCs.

PrivateLinkTo reach AWS services or another company's service without touching the internet, use VPC endpoints. A gateway endpoint (S3, DynamoDB) is a route-table target; an interface endpoint (PrivateLink) puts a network interface with a private IP in your subnet. A provider can expose its own service behind a Network Load Balancer as an endpoint service for consumers in other accounts.
4

Route 53: seven routing policies

Route 53 is AWS's managed DNS, with public and private hosted zones, health checks and a 100% availability SLA (the only AWS service with one). Its routing policies decide which answer each query gets, and you can nest them into traffic policies. Match the need to the policy.

5

At the edge: CloudFront and Global Accelerator

CloudFront is the content delivery network: viewers are routed to the nearest of 300+ edge locations (2022). On a cache hit the edge answers at once; on a miss it fetches from the origin, returns it and keeps a copy until its TTL expires. Fire requests and watch the hit ratio climb.

Global Accelerator also uses the edge network but doesn't cache. It gives you two static anycast IPs and carries TCP or UDP traffic over the AWS backbone to the nearest healthy regional endpoint, such as a load balancer, and fails over automatically. Use CloudFront for cacheable HTTP content; use Global Accelerator for non-HTTP traffic, fixed IPs or fast regional failover. Wavelength goes further out, putting compute inside 5G networks for single-digit-millisecond latency (connected cars, smart factories, live video).

Security groups versus network ACLs

Two firewalls inside the VPC. A security group wraps an instance: allow rules only, all rules evaluated, and stateful (a reply to allowed traffic is allowed automatically). A network ACL guards a subnet: allow and deny rules, evaluated in number order with the first match winning, and stateless (return traffic needs its own rule, usually on ephemeral ports 1024–65535).

Evaluate a NACL

Number rules in steps of 100 (100, 200, 300) so you can slot one in later at 150.

PatternsCreate security groups before launching resources. Reference other SGs instead of IP ranges. Share NACLs by subnet tier. Add AWS Network Firewall (managed, Suricata-compatible rules) or partner firewalls from Palo Alto Networks or Fortinet for deep inspection.
Anti-patternsUsing the default SG for everything. Wide-open 0.0.0.0/0 inbound rules. Forgetting that NACLs are stateless. Never auditing for stale or redundant rules.
