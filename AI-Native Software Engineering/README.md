# AI-Native Software Engineering: visual companion

One self-contained, interactive HTML page per chapter of *AI-Native Software Engineering* by Alfonso Graziano (O'Reilly, early release). Open `index.html` in any browser. No install or server needed. Fonts load from Google Fonts when you're online and fall back gracefully offline.

The explanations and diagrams are original summaries, not reproductions of the book. Numbers marked "illustrative" are teaching models, not figures from the book. Each page has a light/dark toggle (top right) and works at phone width.
