Using First-order Logic

Writing good first-order formulas is a craft: pick the right connective under each quantifier, keep track of which variables are bound, and know which quantifier laws hold.

1

From English to first-order logic

Translating natural language is where first-order logic earns its keep, and where most mistakes happen. The book's advice: identify the domain and the predicates first, find the quantifier words ("every", "some", "no", "only"), then build the formula from the outside in. Choose the right formalisation.

2

The golden rule of restricted quantification

"All circles are red" quantifies over circles only. Restricting ∀ uses →; restricting ∃ uses ∧. Swap them and the meaning collapses. Edit the world and compare the right and wrong versions live.

3

Scope, free and bound variables

Each quantifier ∀x or ∃x has a scope, the subformula it applies to. An occurrence of x inside that scope is bound by the nearest such quantifier; an occurrence outside every x-quantifier is free. The same letter can be free in one place and bound in another. Colours show which quantifier binds each occurrence; free occurrences are red and underlined.

A formula is clean if no variable is both free and bound and no two quantifiers bind the same variable. Any formula can be made clean by renaming bound variables, which never changes its meaning: ∃y Q(x, y) and ∃z Q(x, z) say the same.

4

Substitution and variable capture

Substituting a term t for a free variable x, written A[t/x], is how we instantiate general statements. Danger: if t contains a variable that a quantifier in A binds, it gets captured and the meaning changes. The fix is to rename the bound variable first; then t is free for x in A.

5

Validity, consequence and countermodels

A sentence is logically valid if it is true in every structure for its language, and A₁, …, Aₙ ⊨ B if every structure making all premises true makes B true. There are infinitely many structures, so we can't check them all, but one countermodel refutes a claim. Classic case: quantifier order. Draw a relation L(x, y) ("x likes y") by tapping pairs and compare.

∃y∀x L(x, y) ⊨ ∀x∃y L(x, y) is valid: one person liked by everybody gives everybody someone to like. The converse fails, and a two-person "each likes the other only" picture is a countermodel.

6

Which quantifier laws hold?

Decide whether each pair is logically equivalent. Wrong guesses come with a small countermodel.

7

Negating quantified statements

Negation flips quantifiers as it moves inward: ¬∀x A ≡ ∃x ¬A and ¬∃x A ≡ ∀x ¬A. Together with the propositional rules this gives a negation normal form for first-order formulas. Example: the negation of "every student passed some exam".
