Propositions, Connectives and Truth Tables

A proposition is a sentence that is either true or false. Five connectives glue propositions together, and truth tables tell us exactly how truth flows from the parts to the whole.

1

What counts as a proposition

A proposition is a sentence that has exactly one truth value, true or false, even if we don't know which. "The 1000th decimal digit of π is 9" is a proposition; nobody needs to know the answer. Questions, commands, sentences with unresolved pronouns or free variables, and self-referential sentences are not. Sort these.

2

Five connectives and their truth tables

From atomic propositions we build compound ones with connectives. The truth value of the whole depends only on the truth values of the parts, a kind of "propositional arithmetic". Pick a connective and toggle the inputs; T stands for true, F for false (computer scientists often write 1 and 0).

Priority when parentheses are left out: ¬ binds tightest, then ∧ and ∨, then →, and ↔ is weakest. So ¬p ∨ q → r means ((¬p) ∨ q) → r. Because ∧ and ∨ share a level, always bracket them when mixed.

3

Why “false implies anything” is true

The implication is the connective people argue with most. The book's advice: read it as a promise. A parent says "If you pass your logic exam, I'll buy you a bike." Tap each situation: was the promise kept or broken?

Only one situation breaks the promise. In the others there is no reason to call the parent a liar, and since a proposition must be true or false, it counts as true.

4

Formulas, parse trees and computing a truth value

Propositional formulas are templates built from variables (p, q, r…), constants ⊤, ⊥ and connectives by three rules: every variable or constant is a formula; if A is, so is ¬A; if A, B are, so are (A∧B), (A∨B), (A→B), (A↔B). The last connective applied is the main connective, and the parts built on the way are the subformulas. A truth assignment to the variables flows up the tree.

The default is the book's warm-up sentence "Logic is not easy, or if logic is fun then it is easy and not boring", with e = easy, f = fun, b = boring. With fun true, easy true and boring false, it comes out true: "logic is easy after all".

5

Truth tables, tautologies and satisfiability

A formula behaves like a function from truth assignments to truth values, so we can tabulate it: n variables give 2ⁿ rows. A tautology is true in every row (a law of logic, like x + y = y + x in algebra). A contradiction is false in every row. A formula is satisfiable if some row makes it true and falsifiable if some row makes it false.

6

A smarter check: hunt for a falsifying assignment

Truth tables are reliable but tedious. Instead, try to make the formula false and push the requirements down to the parts. Write A : T for "A must be true", A : F for "must be false". If every attempt demands some formula be both, no falsifying assignment exists: the formula is a tautology. This search becomes Semantic Tableaux in §2.3.

7

Puzzle: truth-tellers and liars

On planet Nologic every inhabitant is either a truth-teller (always says true things) or a liar (always says false things). A visitor asks two of them, P and Q, "Is either of you a liar?" P answers: "At least one of us is a liar." Choose types and see whether the story holds together.

The formal version: let p mean "P is a truth-teller". Whatever P says, the statement p ↔ (what P said) must hold. Here that is p ↔ (¬p ∨ ¬q); its truth table has exactly one true row.
