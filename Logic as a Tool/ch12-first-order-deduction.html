Deduction in First-order Logic

Each propositional deductive system gains rules for ∀ and ∃. The art is all in the side conditions: which terms you may plug in and which names must be fresh.

Extending H: axioms for the quantifiers

Every propositional deductive system extends to first-order logic by adding rules for ∀ and ∃ (and, if wanted, for =). For the axiomatic system H, take all first-order instances of the propositional axioms, treat ∃x A as short for ¬∀x¬A, and add:

∀x A → A[t/x]Instantiation: what holds for all holds for any term t, provided t is free for x in A.
∀x(A → B) → (A → ∀x B)Provided x is not free in A.
GeneralisationFrom A derive ∀x A (when x is not free in the assumptions used).
Equalityx = x, and if x = y then anything true of x is true of y (substitutivity).

Semantic Tableaux with γ and δ rules

First-order tableaux add four rules. Two are γ rules (universal force): T ∀x A and F ∃x A may be instantiated with any ground term, and as often as needed. Two are δ rules (existential force): T ∃x A and F ∀x A are instantiated once, with a new constant that appears nowhere on the branch, because all we know is that some witness exists.

γ: T ∀x A(x)T A(t) for any term talso F ∃x A(x) gives F A(t)
δ: T ∃x A(x)T A(c), c a new constantalso F ∀x A(x) gives F A(c)

Order matters in practiceApply δ rules before γ rules: the new constants created by δ are exactly the terms worth feeding to γ.
No guarantee of terminationγ formulas can be reused forever. If the consequence is valid the tableau will close; if not it may run on. This is unavoidable: first-order validity is undecidable (Church and Turing, 1936).
3

Natural Deduction rules for ∀ and ∃

∀EFrom ∀x A(x) infer A(t) for any term t free for x.
∀IIf A(c) was derived for a constant c that occurs in no open assumption (an arbitrary object), infer ∀x A(x).
∃IFrom A(t) infer ∃x A(x).
∃EFrom ∃x A(x): assume A(c) for a fresh c, derive C not mentioning c, then conclude C and discharge.
