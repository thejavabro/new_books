Why Logic, and a Taste of Paradox

Logic is not a description of how people actually think. It is a toolkit for reasoning that cannot lead you from true premises to a false conclusion. Self-reference shows where the toolkit gets tested.

1

What logic is about, and what it is not

The dictionary says logic studies "the laws of human reasoning". The book pushes back: people mostly reason with emotion, analogy and habit. A better description is that logic tells us how we can reason so that true assumptions and correct rules always lead to true conclusions. Logic is about correctness of argument, not about which facts happen to be true.

Every logical system has three faces. Tap each one.

Two levelsPropositional logic (book chapters 1–2) reasons with whole sentences and their truth values. First-order logic (chapters 3–4) looks inside sentences at objects, properties, relations and the quantifiers "for all" and "there exists".
Sound and completeA deductive system is meant to capture logical consequence exactly. If everything it derives is a genuine consequence it is sound; if every genuine consequence can be derived it is complete. Both together: adequate.

Correctness lives in the form

An argument whose premises and conclusion are all true can still be logically wrong. The test: keep the shape, swap the words. If some swap makes the premises true and the conclusion false, the shape was never safe. Pick an argument form and a vocabulary.

3

The liar: a sentence with no stable truth value

"The sentence you are reading now is not true." Try to give it a truth value and follow what it says. The value keeps flipping. That is why logic insists a proposition must be a sentence with exactly one truth value; the liar sentence does not qualify.

A paradox differs from a fallacy: a fallacy is a reasoning mistake, while a paradox comes from a hidden ambiguity or, most often, from self-reference. The book plays with this too: "this sentence refers to itself" is harmless, "this one does not" is suspicious.

4

Circular reference: Jourdain's card

Self-reference can hide in a loop. On one side of a card: "The sentence on the other side is true." On the other: "The sentence on the other side is false." Assign values and check whether they are consistent with what each sentence claims.

5

Heterological: a word that describes itself only if it doesn't

Call an adjective autological if it describes itself ("short" is short, "English" is English) and heterological otherwise ("long" is not long, "wet" is not wet). Sort these, then face the last word.

6

Berry's paradox: defining the undefinable

With at most n English words you can only write finitely many descriptions, so some numbers have no description that short, and there must be a least such number. Now describe it.

The way out is that "definable in English" is not itself a precise, first-order notion. Making languages precise is exactly what the rest of the book is about. Russell's paradox about sets, which really did shake mathematics, comes back in §5.2.
