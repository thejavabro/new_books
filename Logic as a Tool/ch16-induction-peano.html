Mathematical Induction and Peano Arithmetic

Induction is the domino principle made rigorous. Peano Arithmetic builds all of number theory from 0, successor and a handful of axioms, and Gödel showed where that stops.

1

Induction: the domino principle

To prove P(n) for every natural number: prove the base case P(0), and the inductive step P(n) → P(n + 1) for arbitrary n. In first-order form: P(0) ∧ ∀n(P(n) → P(n+1)) → ∀n P(n). It is the inductive-definition principle of §1.4 applied to ℕ = "0 and its successors". Break a piece and watch the chain stop.

2

A worked proof, with a picture

Claim: 1 + 3 + 5 + … + (2n − 1) = n². Base: for n = 1 both sides are 1. Step: if the first n odd numbers sum to n², adding the next one, 2n + 1, gives n² + 2n + 1 = (n + 1)². The picture: each odd number is an L-shaped layer that grows an n × n square into an (n + 1) × (n + 1) one.

5

Peano Arithmetic

Peano Arithmetic (PA) is a first-order theory in the language with constant 0, successor s, and +, ·. Numerals are the terms 0, s(0), s(s(0)), …. Its axioms (free variables read universally):

PA1s(x) ≠ 00 is not a successor
PA2s(x) = s(y) → x = ysuccessor is injective
PA3x + 0 = xaddition, base
PA4x + s(y) = s(x + y)addition, recursion
PA5x · 0 = 0multiplication, base
PA6x · s(y) = x · y + xmultiplication, recursion
PA7A(0) ∧ ∀x(A(x) → A(s(x))) → ∀x A(x)induction scheme: one axiom per formula A
Only definable propertiesPA7 covers only properties expressible by a formula of the language. There are countably many formulas but, by Cantor, uncountably many sets of numbers, so most sets are out of reach of the scheme.
Gödel's limitsFirst incompleteness theorem: no consistent, effectively axiomatised extension of PA proves or refutes every sentence. Second: such a theory cannot prove its own consistency.
