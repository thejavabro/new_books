# Fundamentals of Software Architecture: visual companion

Interactive, one-page-per-chapter study notes for all 27 chapters of the 2nd edition, with clickable diagrams, step-through animations, calculators and quick checks.

## Use it
- Open `index.html` in any browser (double-click it). No install or build step; every chapter is a single self-contained HTML file.
- Or put this folder in a GitHub repo and turn on **Settings > Pages** to read it online. All links are relative, so it works after cloning.

Fonts load from Google Fonts. Offline, the pages fall back to system fonts and still work.
