# Transformation Enterprise Architecture with Agentic AI: visual companion

Interactive visual learning pages for *Transformation Enterprise Architecture with Agentic AI: Designing Intelligent, Adaptive, and Self-Governing Systems* by Shivakumar R. Goniwada (Apress, 2026).

Each chapter has one self-contained HTML page with diagrams you can click, small simulations, step-through walkthroughs, a quick-check quiz and a one-page recap. Pages support light and dark themes (follows the system, with a toggle) and work at phone width.

## How to open

Open `index.html` in any modern browser. Everything is inline, so the pages work offline; the Google Fonts stylesheet is optional and falls back to system fonts. Pages link to each other with relative paths, so keep the files together in one folder.

## About the content

All explanations, examples, code snippets and drawings are original summaries written for this companion. They are not text or figures copied from the book; quoted phrases are kept to a few words. Numbers in simulations are illustrative unless a chapter says otherwise.
