Building up a system, one pattern at a time

Patterns rarely work alone. To see it, build a small sensor-monitoring system step by step, each step solving one new requirement with one pattern. Step through and watch the design grow. (The book does the same exercise with its duck simulator; the moves are the same.)

Run the finished system

A compound pattern is more than several patternsUsing five patterns together isn't automatically a compound pattern. A compound pattern combines two or more patterns into a general solution that solves a recurring problem. The sensor system is a design that uses patterns; MVC, below, is a real compound pattern.

Model-View-Controller, live

A thermostat app. The model holds the data and logic (target temperature, current temperature, heating on or off) and knows nothing about screens. Views display the model. The controller turns user input into calls on the model. Change the target in the dial view or the text view and watch every view update.
