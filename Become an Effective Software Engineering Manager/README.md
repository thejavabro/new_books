# Become an Effective Software Engineering Manager: visual companion

An interactive, chapter-by-chapter visual guide to *Become an Effective Software Engineering Manager* by James Stanier (Pragmatic Bookshelf, 2020). Each chapter is one self-contained HTML page with diagrams, small simulations, a quiz and a one-page recap.

## How to open

Unzip the folder and open `index.html` in any modern browser. Everything works offline; no install or server needed. Pages link to each other with relative links, have a table of contents and previous/next navigation, work on phones (390 px wide and up), and follow your system's light or dark mode (or use the theme button).

## Notes

- The explanations are original summaries written for this guide, not text copied from the book. Short phrases and figures are attributed to the book. Read the book for the full argument.
- Coverage: all 18 chapters plus the Introduction (merged into Chapter 1). Front matter and the bibliography are not reproduced. No chapter content is missing.
- A few tools (self-scores, timeline, skills backlog, theme) remember your entries in this browser only. Nothing is sent anywhere.
