Plugins, Connectors and Skills

Connectors let Claude reach your apps, skills teach it a procedure, and plugins bundle both. Add only what a task needs, and grant only the access it needs.

1

Plugin, connector, skill, sub-agent

You can extend Claude in three related ways. A skill is a written playbook: reusable instructions, examples and resources for one kind of work. A connector is a doorway into another service (Google Drive, SharePoint, Slack, GitHub, Gmail) and only opens as far as you allow. A plugin is an installable box that bundles skills, connectors and sometimes sub-agents (separate Claude instances that take a noisy task and report back a summary). Tap each.

2

Every connector request follows the same chain

Your request goes to Claude, through the connector, to the information it selects, and then into the output. Most problems are caught by reviewing the selected information before you trust the output. Step through.

3

Find capabilities in Customize

The book's tour (mid-2026): the sidebar's Customize area has Skills, Connectors and Plugins; some plugins come preinstalled; a Directory lists plugins from Anthropic and partners. Install only what the task needs: to work with a file you can simply upload it. A good listing tells you what the plugin does, its skills and connectors (required or optional), the sign-in and permissions, and where it works. A greyed-out Install or Connect button may mean your administrator restricts it.

4

Read the authorisation screen

Check which account you are connecting, what it can read, and whether it can change anything. Reading is different from deleting, sending, sharing or replacing. Prefer settings that ask before making changes. If a plugin wants more than its purpose needs, do not connect. Decide on this invented request for a "Meeting Notes Summariser".

    5

    A connection reaches everything in scope

    Connecting a source lets Claude search everything within the approved scope, not just files for today's task. Narrow every request by folder, date range or sender, and name the connector explicitly when several could answer (for example with @ and its name, the + menu, or as a Cowork source). Each square is a file in your drive.

    6

    Cite, check, and disconnect when done

    Ask Claude to name or link the file or message behind each claim and open a sample yourself, as you would with a colleague's summary of documents you had not read. When a project ends, disconnect: removing access does not delete anything in the other service, it just closes the door. Connected plugins keep working quietly, so review them now and then.
