Write, Refine and Improve Prompts

A good prompt is less a magic phrase than a clear brief. And the first reply is a draft: the real skill is steering it with follow-ups.

1

A prompt in four parts

A prompt is just the message you send. A useful one names the task and outcome, gives relevant context, sets constraints and boundaries, and asks for a form of answer. No magic words; everyday language is fine. The order matters less than whether the information is there. Build one for an invented example: a one-hour session teaching older adults to make video calls.

2

Relevant context, not every detail

Context is whatever would change the answer if it were missing: the audience, what they already know, the purpose, the materials. Extra details distract. And anything from a document or photo should be stripped of names, contact details and faces the task does not need. Keep or cut each detail.

3

Constraints you can actually check

Constraints are limits (time, budget, length, tools, number of options). Boundaries say what Claude must not do. Both work only if they are specific enough to verify, and a boundary rules out only what you name: "do not invent prices" does nothing to stop an invented venue. Which of these can you check in the reply?

Change one part, keep the rest

Say which part needs work, what must stay, and ask to see only the changed section. Then compare. Claude sometimes changes more than asked; if so, point at the extra change and ask for the earlier version back. Below, the review found too little practice time.

7

Same chat or a new one?

Stay in the same chat when the next request depends on what came before. Start a new chat for a new subject. If you must restart, paste a short summary, your criteria and the current version.

Try it now: one prompt, improved through conversation

Pick a personal planning, learning or writing task with a visible result. Write a four-part prompt, ask what is missing, request two or three alternatives that differ in one named way, review one against your own criteria, then make one focused change.
