Files, Memory, Projects and Your AI Workbench

Give Claude the right material and it stops guessing. Save the context you repeat, organize work into projects, then assemble it all into a personal workbench.

1

Upload a file, then explain the assignment

Use + in the chat box to add a PDF, Word document, image, spreadsheet or CSV from your device or a connected cloud drive (Excel files need code execution and file creation switched on). Free accounts get a limited number of uploads per day. An upload alone is not a request: say what the file is, who the result is for, and the shape you want back, as you would when handing a document to a colleague. Tap a file type.

Before you uploadNo passwords, private keys, medical records or other people's personal data unless you have the right to share them. For work documents, check your organisation's rules first (Chapter 2.1).
2

Extract to a table, then check it against the original

Ask for specific details by name in a structured format ("every date, amount and named party, as a table"). A table is easier to check than a paragraph. Keep the original open beside the result. This invented extraction has two mistakes: tap the cells you think are wrong.

TENANCY SUMMARY (sample)
Landlord: Hollis Property Ltd
Tenant: J. Rivera
Start date: 01/09/2026
Monthly rent: £950, due on the 1st
Deposit: £1,100
Notice period: two months
Pets: only with written consent
Find 2 mistakes
Watch the usual suspectsMisread numbers, dropped rows, merged cells, ambiguous date formats (is 01/09 the 1st of September or 9th of January?), and names from handwriting or glare-filled photos.
3

Compare documents on the points you care about

Upload several files in one chat (supplier quotes, two versions of a document, CVs against a job description) and name the comparison points. Without them, Claude may compare the details that matter least to you. Pick your points and see the prompt.

4

Photos, whiteboards and screenshots

Claude can read printed and handwritten text, describe a photo and answer questions about a chart. You can also attach a screenshot straight from the + menu: the browser asks which tab, window or entire screen to share (the desktop app needs screen-recording permission). Capture only what Claude needs.

5

Instructions, memory, projects and incognito

Four ways to stop repeating yourself, each with a different reach. Instructions for Claude are rules you save once in settings and apply to every new chat. Memory is facts Claude picks up (or you ask it to remember) plus recall of earlier chats; on paid plans. A project groups chats, files and instructions for one ongoing job and keeps its own memory. An incognito chat uses none of it and leaves no trace. Choose where you are chatting.

When a reply looks oddly shapedInstructions and memory apply even when you have forgotten them. A surprisingly short, informal or oddly specific answer may be following a saved rule. Check your instructions and memory before blaming the prompt.
6

Keep memory accurate

Review saved memories every few months. You can switch off memory from chats, delete an entry, or add one. True or false?

7

Project: build your personal AI workbench

Book 1 ends by combining everything into one project for a task you will repeat. Choose a track, write one sentence describing a finished result (you will judge the output against it), name the project after the task ("Monthly Client Summary", not "Bookkeeping"), add instructions and reference files, run the task once for real, and note what to improve.

Tap a stage of the loop.

If the task depends on todayPrices or availability? Plan to search or run Research inside the project each time rather than relying only on saved files.
