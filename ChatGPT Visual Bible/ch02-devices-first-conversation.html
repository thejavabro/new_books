Web, Phone, Desktop and a First Real Conversation

The same account follows you across browser, phone and desktop. Whichever door you use, a useful conversation follows one loop: name the result, answer questions, correct assumptions, compare alternatives, keep what works.

1

Three doors into one account

ChatGPT runs in a browser, in iPhone and Android apps, and in desktop apps for Mac and Windows. Sign in with the same method everywhere and your conversations follow you. Each door has a strength. Pick a situation and see which the book recommends.

Watch out: same method, same accountIf you created the account with Google, sign in with Google on every device. A different route (say, email) can quietly create a second account with its own empty history and its own plan.
2

Get there the safe way

A search result, an advert or a copied link can lead to a look-alike site or app. The book's habit: type chatgpt.com yourself, bookmark it, install apps only where OpenAI is the listed publisher, and download the desktop app only from chatgpt.com/download. Spot the safe routes.

Safe or suspicious?

The phone app will ask for microphone, camera, photo and notification access. Grant each only when you know why a feature needs it (Dictate and Voice need the microphone; asking about a photo needs that one photo). On a desktop, never give access to a folder or app "because it might be useful later". Ask before installing on an employer's computer.

3

Continue a conversation on another device

Start in a browser, read the reply on your phone, finish on a computer. The book's test is a harmless "cross-device test" chat: send it on one device, reply from the other, check it comes back. Some things deliberately do not travel. Tap each item.

Good practice: one subject per chatSwitch from vacation planning to a work memo? Start a new chat. A focused conversation gives ChatGPT less unrelated text to misread and is easier to find later. If a chat is missing on another device, check the account and workspace on both before pasting the same private material again.
Likely changed since publicationThe book describes a desktop app that combines Chat, Work and Codex, an optional pop-out window hotkey (off by default, set under Settings → General), a "Sites" entry, an in-app browser pane, macOS Appshots, and live camera in Voice only on paid plans. It also quotes OpenAI saying it planned to fold the separate Work mode into ChatGPT by the end of 2026. Desktop layouts were explicitly in flux, so expect names and positions to differ.
4

Type, dictate, talk or show

The input changes how you give information; the conversation habits do not. ChatGPT replies in the language you write or speak by default (the book cites around 58 natively supported languages; quality is best in widely used ones). Match the input to the job.

Which input fits?

Watch outA photo can reveal more than its subject: backgrounds, reflections, labels and file names. Voice can capture people nearby. Crop first, move somewhere private, and read the Voice transcript before relying on it.
5

How hard should it think?

A thinking-effort control in the chat box trades speed for depth. More thinking is not more correctness: it gives the model more room to reason, and overthinking is a real failure mode. Match the level to the task.

Likely changed since publicationThe book (as of August 2026) names five levels (Instant, Medium, High, Extra High, Pro), says Plus gets the first three and Pro all five, and ties them to a model family called GPT-5.6 with Sol (most capable), Terra (balanced) and Luna (fastest, default for Free and Go), with older versions such as GPT-5.5 and o3 under an Advanced menu. Model names, defaults and which plan gets which level change with every rollout; OpenAI's Models page is the live source.
6

The improvement loop

Whatever the input, a useful conversation runs the same five-step loop. The book's example is choosing a gift for a neighbour who likes gardening. Step through it.

A correction does not need to repeat the whole task; it only changes the wrong part. If ChatGPT still guesses, ask it to label each assumption and list what it needs from you. When you're done, rename the chat ("Balcony gift ideas, July") and copy the result, with its checks, into your own document. Shared links let anyone holding them view the whole conversation, so read it all before sharing.
