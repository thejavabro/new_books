Reusable Skills and Custom GPTs

A skill packages one proven procedure; a Custom GPT packages a whole assistant. Both succeed or fail on the specification you write before building and the difficult test case you run after.

1

A skill starts as a specification, not a prompt

A skill stores a tested procedure so ChatGPT can repeat it consistently. Preparation matters more than the build: a skill built from a vague procedure behaves inconsistently however carefully you set it up. Pick a procedure you've done the same way several times. The book's example: a marketing coordinator who has turned each new blog post into a three-sentence social summary the same way for two months.

Name
Blog Post Social Summary
Inputs
The blog post (text or public link) · target audience
Steps
Read the post → find the main point → write three sentences → end with one call to action
Rules
Only facts stated in the post · plain, friendly tone · if a required input is missing, ask one focused question and wait
Worked example
One real input and the exact output you wanted (an example often teaches a rule faster than words)
Acceptance
Exactly three sentences · one clear call to action at the end · no claim absent from the post

Write acceptance criteria before building, as a checklist you can verify by looking. Deciding "good" in advance stops you lowering the bar when you see the first result.

2

Build, then test a normal case and a hard case

You create a skill through conversation: attach the spec, ask ChatGPT to draft the skill's instructions and confirm inputs and outputs, review against your criteria, save. Then test. A skill that only works on easy cases isn't ready. Run both tests, then add the missing rule and run them again.

Test 1 · normal casePost: free 30-minute planning clinics every Thursday at 1:00, starting 10 Sept. Audience: new customers.
Not run yet.
Test 2 · hard casePost: a new guide to planning a first project. Audience: (not provided).
Not run yet.

When a test fails, fix the instruction, not the outputDon't keep correcting results by hand or rerunning in hope. Find the missing or unclear instruction, update the skill, then rerun both tests to confirm the fix didn't break what worked. Run three or four varied inputs before trusting it on real work.
3

Invoke it, then share it carefully

Once it passes, invoke the skill by name with a dollar sign and give the inputs, or invoke it bare and let it ask for each input in turn. You don't repeat the steps or rules; they live in the skill.

$blog-post-social-summary Blog post: https://example.com/posts/planning-clinics Target audience: new customers planning their first project
Likely changed since publicationAs printed: skills were listed under Plugins → Skills with a status such as Installed, invoked with $skill-name, and shareable to a workspace from the skill's settings. Exact invocation syntax and where skills live are product details to recheck.
4

When a Custom GPT is the better mechanism

A skill stores one procedure. A Custom GPT is a whole assistant for one purpose: its own instructions, knowledge files, conversation starters and capabilities. Build one when several skills must work together, when the assistant should always start from the same role and knowledge, or when several people return to the same kind of task. If unsure, start with a skill; you can combine later.

Skill or Custom GPT?

Likely changed since publicationThe book states that creating or editing Custom GPTs was not available on personal accounts (Free, Go, Plus or Pro) at the time, and that workspace settings controlled creation and sharing in Business, Enterprise and Edu. That contradicts the introduction's "Plus covers everything" and is exactly the kind of availability rule that moves. Check before planning around it.
5

Configure a GPT: each part has one job

The book builds a "Workshop Planner" for its fictional company. Behaviour and workflow rules go in Instructions (written like a briefing for a new colleague, with headings and explicit steps for multi-stage work). Reference material goes in Knowledge files. Conversation starters are realistic example prompts that each reveal a different ability. Turn on only the capabilities the job needs. Toggle them and see what the planner can and can't do.

Leave Actions unconfiguredThis planner prepares recommendations and drafts. It must not book venues, publish events, spend money or contact attendees, so it gets no Actions at all. Extra access adds risk without adding value.
6

Share it, then keep its knowledge current

Watch outA GPT's knowledge files are only as current as your last upload. When the policy, price list or process changes, update the GPT, or its answers go stale without any warning. Test it with a question outside its scope, too.
