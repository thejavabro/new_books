Write, Refine and Improve Prompts

A prompt is just a clear request. Give it four ingredients (outcome, context, limits, form), then keep talking: ask what is missing, compare alternatives, check against criteria and revise one part at a time.

1

A prompt in four parts

A prompt is the message you send. It needs no magic words, only enough plain information for a suitable first answer. The book uses a running example: a 60-minute class for adults new to smartphone photography. Switch parts on and off and watch the prompt, and the likely answer, change.

Task and outcomeAn action (plan, explain, compare, draft) and a result you can inspect (an agenda, a checklist, a table).
Relevant contextAudience, what they know, purpose, materials. Only facts that would change the answer; a favourite film would not.
Constraints and boundariesLimits it must follow (time, budget, length, tools) and things it must not do.
Form of the answerTable with named columns, numbered steps, headings, length, reading level, tone.

3

Limits you can actually check

A boundary only rules out what you name. "Don't invent local rules" does not stop ChatGPT inventing a different detail you forgot to mention. And a limit is only useful if you can verify the answer met it: "keep it reasonable" cannot be checked; "under 500 words" can.

4

Improve the first answer through conversation

The first answer is something to inspect, not the finish line. The book continues the class example through four moves. Step through them.

Watch out: ChatGPT judging ChatGPTAsking it to review its own answer against your criteria is still the same model marking its own homework; it can pass a weak answer. Spot-check at least one criterion yourself.
5

Review against criteria you wrote first

Criteria are the checks you use to judge an answer: facts from the task (60 minutes) and qualities you want (a privacy reminder in every activity). Here is a first draft plan. Tick each criterion only if you can see it is met.

Good practiceNew subject, new chat. Same task, same chat. If you must restart, paste a short task summary, your criteria and the current version. For long work, keep a dated copy of approved text before asking for a big rewrite.
