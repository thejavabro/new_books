Plugins, Apps, Skills and a Weekly Briefing

Plugins bundle skills (playbooks) and apps (doorways to other services). Grant the least access the task needs, then pull everything from Book 2 together into a weekly briefing built on an evidence table.

Plugins, apps and skills: how the pieces fit

A skill is a written playbook: reusable instructions, examples and resources for one kind of work (inspect a spreadsheet, chart it, check the workbook). An app is a doorway into another service (find a file in Google Drive, search Slack, read a Notion page) that can only use the access you and your organisation allow. A plugin is the installable box that bundles skills, apps or both. Tap the diagram.

Every app call passes through the same chain. Reviewing the selected information before the output stage catches most problems.

2

Install only what the task needs

You don't need to connect Drive or Microsoft 365 just to work on a file: you can upload it. Search for the result you want ("presentation creation", "project reporting") rather than installing everything that sounds interesting. A good listing tells you what it does, which skills and apps it contains, which apps are required or optional, setup and sign-in, supported surfaces, and requested permissions. In a managed account an administrator may decide what's available; a greyed-out Connect button often means exactly that.

Likely changed since publicationThe book describes a Plugin Directory (Plugins in the sidebar, with a Plugins/Skills switch) that had just replaced the earlier App Directory, common document, spreadsheet and presentation plugins installed by default, @-mentioning a plugin by name, and tool statuses such as Running, Waiting for approval and Complete. This whole area was new in 2026 and is likely to have been reorganised.
3

Grant the least access that does the job

Connecting can let ChatGPT read information or take actions in another service. Read the authorisation screen: which account, what it can see, whether it can change things. Prefer settings that ask before making changes; reading a document is very different from deleting, sending or sharing it. Your existing permissions in the source still apply. Choose permissions for this task:

Task"Summarise this week's emails about Project Atlas and list the meetings I have with that team on my calendar."
0

Watch outA connection lets ChatGPT search everything inside the scope you approve, not just files related to today's task, and a connected plugin keeps working after you stop using it. Review connections occasionally; when a project ends, open your connected plugins, choose Disconnect or Remove access, and confirm. That stops future access without deleting anything in the other service.
4

Point it at the right source, then check the citations

When more than one installed capability could handle a request, or you need a particular service, select it explicitly and name the boundaries. Then ask it to name or link the file or message behind each claim, and open a sample yourself.

Good practiceTreat a connected search like a colleague's summary of documents you haven't read: a useful start, worth checking before you repeat it as fact. An office manager in the book asks for every vendor contract expiring in 60 days, then opens each cited file to confirm the date before renewing.
5

Book 2 project: a weekly briefing you approve every week

The project combines everything in Book 2 into a one-page weekly operations briefing for a managing director and programme manager (the fictional training business again). The essential move is an intermediate evidence table that separates gathering facts from writing persuasive prose. Your approval sits between draft and finished briefing every week, not only the first time.

An evidence table (invented figures)

Rules the book builds in: attendance = total attendees ÷ total capacity; known net revenue from delivered sessions only; missing satisfaction excluded and counted; last week's briefing for structure and tone only, never as current figures; anything unsupported marked [CHECK].

Watch out: missing is not zeroA satisfaction survey that is still open should be reported as pending, not averaged in as a 0 or silently dropped without saying so.
6

Review the draft against the sources

Before editing, the book has ChatGPT build a review table: each claim, the source checked, a result (Supported, Incorrect, Incomplete, Unsupported), the fix and a priority. Then you approve only the high-priority changes and get a new file so the old version survives. Classify these draft claims against the evidence table above.
