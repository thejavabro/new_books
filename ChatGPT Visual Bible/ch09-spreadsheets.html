Analyze Spreadsheets and Data

ChatGPT can run real code on your spreadsheet. The trick is order: explain the data before touching it, clean it with a change log, calculate what answers the question, then check the numbers yourself before deciding.

1

Five steps, with validation before the decision

ChatGPT can run real code in a secure analysis environment to clean, summarise, chart and project data. The book follows a fictional training provider deciding which workshops to run more often. Its five steps put validation deliberately between analysis and decision: a chart is not a decision until you've checked the numbers behind it. The small dataset on this page is invented to show the same ideas.

2

Step 1: explain the data and the question

"What does this spreadsheet show?" gets a vague answer. "Which course earns the most per session, without hurting attendance or satisfaction?" gives it something to calculate. Before changing anything, ask ChatGPT to explain what one row represents, what each column holds and what kind of data it is, and what the data cannot tell you. Tap a column header.

One row = one workshop session. Tap a header.

3

Step 2: clean with a change log, never by guessing

Ask it to check for duplicates, missing values, inconsistent spelling, mixed date formats, values out of range and bookings above capacity, and to keep the original sheet unchanged, write cleaned data to a new sheet, and record every issue in a "Data Issues" sheet. Remove only exact duplicates; standardise labels only when they clearly mean the same thing; never fill a missing value or "fix" a questionable figure by guessing.

Amber = issue found · green = safely fixed · red = flagged for a human
Original rows: 8. Press Clean.
4

Step 3: calculate what answers the question

Ask for specific formulas kept visible in the workbook: Attended = Bookings − No-shows; Gross = Bookings × Fee; Net = Gross − Refunds (left blank, and flagged, if Refunds is missing); Attendance rate = Attended ÷ Bookings. Then summarise by course and chart the comparison that matters. The book's choice of average net revenue per session is deliberate. Toggle and see why.

5

Step 4: check it yourself

Pick a few rows and do the arithmetic. Ask how many rows each calculation used and whether any were excluded. Here's one row from the cleaned data: work out its net revenue.

A classic trap: averaging percentages

The book's prompts insist on overall attendance rate (total attended ÷ total bookings), not the average of each session's percentage. Small sessions distort the second.

Good practiceAsk for the method in plain language before trusting the result; if you can't follow it, ask again more simply. A shop manager in the book checks the answer against the three weakest rows by hand before changing any orders. Then ask: "Which single number here would change my decision if it were wrong?"
