Two scripts for the same factory

Run both assembly lines. Script A asks "how do we catch defects cheaply?" and inspects at the end. Script B asks "why does any defect happen?" and stops the line at the station that made it, so the cause gets fixed.

A toy model: in Script B each stop removes part of a station's cause, so the defect rate falls. Script A keeps paying for rework forever because nothing upstream ever learns.
