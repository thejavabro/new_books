# Framed!: visual companion

Interactive, one-page-per-chapter study notes for *Framed! Solve an Intriguing Mystery and Master How to Make Smart Choices*. Each page has diagrams, animations, sliders, simulations, sorting games and a quick check.

## Use it
- Unzip into `C:\repo\new_books\` (you'll get a `Framed` folder).
- Open `index.html` in any browser. You don't need to install or build anything, and every page is self-contained.
- Fonts load from Google Fonts. Offline, pages fall back to system fonts and still work.
- **Spoilers:** chapters 18–20 and the epilogue reveal who the killer is.
