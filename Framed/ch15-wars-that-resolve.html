WARS that Resolve

When there are more than two options and several factors, Larry reaches for WARS: list the alternatives, weigh each attribute by importance, score each option on each attribute, multiply and add. Then argue about the assumptions.

Recap on one page

WARSWeighing Attributes and Rating Scores: a general method for multi-option, multi-factor choices.
Five stepsAlternatives in columns; weights per attribute; scores per cell; multiply; add.
Keep them separateWeight = importance. Score = assessment. Mixing them muddles both.
A framework, not an oracleIt forces you to confront every attribute for every option. Judgment still decides.
Close calls87 vs. 83 is a dead heat. Small changes in assumptions can flip it.
Find the gapsThe grid shows where you need more information: motives, alibis, missing suspects.
