How to approach a brain teaser

The chapter's advice: don't panic. Read the problem several times, write down what is input, what is output and what the constraints are, then try small cases by hand until a pattern appears. Many "puzzles" are just a counting argument, a known sequence or a greedy choice that you can justify with a worst case. And some companies avoid them altogether; they are popular in phone screens and online tests.

1 · ClarifyInputs, outputs, ranges, overflow, negative numbers.
2 · Small casesn = 1, 2, 3, 4 on paper. Tabulate the answers.
3 · Pattern, then proofGuess the rule, check it on one more case, explain why it holds.

FizzBuzz, the famous filter

Print 1 to n, but "Fizz" for multiples of 3, "Buzz" for multiples of 5 and "FizzBuzz" for both. The only trap is the order of checks: test 15 (both) first, or build the string by appending.

for (int i = 1; i <= n; i++) {
    if (i % 15 == 0)     System.out.println("FizzBuzz");
    else if (i % 3 == 0) System.out.println("Fizz");
    else if (i % 5 == 0) System.out.println("Buzz");
    else                 System.out.println(i);
}
3

Roman numerals, greedily

Converting a number to Roman numerals is greedy: walk a table of values from largest to smallest, including the subtractive pairs (CM, CD, XC, XL, IX, IV), and take each as many times as it fits. Going back, add each symbol's value, but subtract it when a larger symbol follows.

String toRoman(int n) {
    int[] v = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
    String[] s = {"M","CM","D","CD","C","XC","L","XL","X","IX","V","IV","I"};
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < v.length; i++)
        while (n >= v[i]) { n -= v[i]; sb.append(s[i]); }
    return sb.toString();
}
4

Visiting and toggling 100 doors

100 closed doors. On pass 1 you toggle every door, on pass 2 every second door, on pass k every k-th door, for 100 passes. Which doors end open? Door d is toggled once per divisor of d. Divisors come in pairs (2 × 6 = 12) except when d is a perfect square (6 × 6 = 36), which has an odd count. So only 1, 4, 9, …, 100 stay open.

8 teams: how many wins guarantee the semi-finals?

8 teams each play every other team twice (14 games each, 56 in total). The top 4 go through. How many points (1 per win) guarantee a place? Think about the worst case: teams beat everyone below them, so the scores are 0, 2, 4, …, 14. The top four share 8 + 10 + 12 + 14 = 44 points; a team with 11 cannot be beaten by four others who all have more, since that would need more than 44 points among them. Drag to see.

The k-th number whose only prime factors are 3, 5 and 7

The sequence is 1, 3, 5, 7, 9, 15, 21, 25, … Every number in it is an earlier number times 3, 5 or 7. Keep three pointers into the list built so far; the next value is the smallest of 3·a[i3], 5·a[i5], 7·a[i7]; advance every pointer that produced it (so duplicates like 15 = 3·5 = 5·3 appear once). O(k).

long kth357(int k) {
    long[] a = new long[k];
    a[0] = 1;
    int i3 = 0, i5 = 0, i7 = 0;
    for (int n = 1; n < k; n++) {
        long next = Math.min(a[i3] * 3, Math.min(a[i5] * 5, a[i7] * 7));
        a[n] = next;
        if (next == a[i3] * 3) i3++;
        if (next == a[i5] * 5) i5++;
        if (next == a[i7] * 7) i7++;
    }
    return a[k - 1];
}
7

Count the decodings of a digit sequence

With A = 1 … Z = 26, "1234" decodes as ABCD, LCD or AWD: 3 ways. It is the staircase problem in disguise: the last letter used either one digit (if it is not 0) or two digits (if they form 10–26). ways[i] = ways[i−1] (single) + ways[i−2] (pair).

int decodings(String s) {
    int prev2 = 1, prev1 = s.charAt(0) != '0' ? 1 : 0;      // ways[i-2], ways[i-1]
    for (int i = 2; i <= s.length(); i++) {
        int cur = 0;
        if (s.charAt(i - 1) != '0') cur += prev1;
        int two = Integer.parseInt(s.substring(i - 2, i));
        if (two >= 10 && two <= 26) cur += prev2;
        prev2 = prev1; prev1 = cur;
    }
    return prev1;
}
8

Do two rectangles overlap?

It is easier to test when they do not: one is entirely left of, right of, above or below the other. Overlap is the negation. Move the second rectangle.

record Rect(int left, int top, int right, int bottom) { }   // y grows downward

boolean overlap(Rect a, Rect b) {
    return !(a.right() <= b.left() || b.right() <= a.left()
          || a.bottom() <= b.top() || b.bottom() <= a.top());
}
9

Multiplying large numbers digit by digit

When numbers exceed long, multiply the way you learned at school: digit i of the first times digit j of the second lands in position i + j + 1 of the result array, then carries propagate. (In practice BigInteger does this, but the interviewer wants the algorithm.)

String multiply(String a, String b) {
    int[] r = new int[a.length() + b.length()];
    for (int i = a.length() - 1; i >= 0; i--)
        for (int j = b.length() - 1; j >= 0; j--) {
            int sum = (a.charAt(i) - '0') * (b.charAt(j) - '0') + r[i + j + 1];
            r[i + j + 1] = sum % 10;
            r[i + j] += sum / 10;                        // carry left
        }
    StringBuilder sb = new StringBuilder();
    for (int d : r) if (!(sb.length() == 0 && d == 0)) sb.append(d);
    return sb.length() == 0 ? "0" : sb.toString();
}
10

Next greater number with the same digits

From the right, find the first digit that is smaller than the digit after it (the pivot). Swap it with the smallest larger digit to its right, then reverse the tail so it is as small as possible. If no pivot exists, the digits are in descending order and there is no greater number.

The angle between the clock hands

The minute hand moves 6° per minute. The hour hand moves 30° per hour plus 0.5° per minute, the detail people forget. The angle is the absolute difference, folded to at most 180°.

double angle(int h, int m) {
    double hour = (h % 12) * 30 + m * 0.5;
    double minute = m * 6;
    double d = Math.abs(hour - minute);
    return Math.min(d, 360 - d);
}
12

Scheduling one elevator

n people on the ground floor, an elevator of capacity k, one time unit per floor. Minimize the total time to deliver everyone and return. Greedy: sort the destinations in descending order and send the k highest together. Each trip costs 2 × its highest floor, and grouping the high floors means they never pay twice.

int schedule(int[] floors, int k) {
    Integer[] f = Arrays.stream(floors).boxed().sorted(Comparator.reverseOrder()).toArray(Integer[]::new);
    int time = 0;
    for (int i = 0; i < f.length; i += k) time += 2 * f[i];   // f[i] is the trip's top floor
    return time;
}
