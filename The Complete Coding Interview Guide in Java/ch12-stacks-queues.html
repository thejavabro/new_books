Stacks and Queues

A stack remembers the most recent thing; a queue remembers the oldest. Choosing the right one turns a nested-loop problem into one clean pass, and a grid search into BFS or DFS.

Stacks and queues in a nutshell

A stack is last in, first out (LIFO): push, pop and peek all work on the top in O(1). A queue is first in, first out (FIFO): offer at the back, poll from the front. In modern Java, use ArrayDeque for both rather than the legacy, synchronized Stack class.

Balanced brackets: the stack's signature problem

Push every opening bracket. On a closing bracket, the top must be its partner; pop it. At the end the stack must be empty. Anything else is unbalanced. (The chapter's version uses curly braces only; the same code handles all three kinds.)

boolean balanced(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        switch (c) {
            case '(', '[', '{' -> st.push(c);
            case ')' -> { if (st.isEmpty() || st.pop() != '(') return false; }
            case ']' -> { if (st.isEmpty() || st.pop() != '[') return false; }
            case '}' -> { if (st.isEmpty() || st.pop() != '{') return false; }
            default -> { }
        }
    }
    return st.isEmpty();
}

Stock span: a monotonic stack

The span of day i is how many consecutive days up to and including i had a price ≤ today's. Keep a stack of indexes whose prices are decreasing. For each new day, pop every index with a lower or equal price (they can never be the "previous higher day" again). The span is the distance to whatever remains on top. Every index is pushed and popped once: O(n).

stack (indexes): 
int[] span(int[] price) {
    int[] span = new int[price.length];
    Deque<Integer> st = new ArrayDeque<>();          // indexes, prices decreasing
    for (int i = 0; i < price.length; i++) {
        while (!st.isEmpty() && price[st.peek()] <= price[i]) st.pop();
        span[i] = st.isEmpty() ? i + 1 : i - st.peek();
        st.push(i);
    }
    return span;
}

Largest rectangle in a histogram

Another monotonic stack. Keep bar indexes with increasing heights. When a shorter bar arrives, every taller bar on the stack has found its right boundary; pop it and compute its rectangle: height × (distance between the new bar and the bar now below it on the stack). A sentinel height 0 at the end flushes the stack.

int maxArea(int[] h) {
    Deque<Integer> st = new ArrayDeque<>();
    int best = 0;
    for (int i = 0; i <= h.length; i++) {
        int cur = (i == h.length) ? 0 : h[i];             // sentinel
        while (!st.isEmpty() && h[st.peek()] > cur) {
            int height = h[st.pop()];
            int left = st.isEmpty() ? -1 : st.peek();
            best = Math.max(best, height * (i - left - 1));
        }
        st.push(i);
    }
    return best;
}

Smallest number after removing k digits

Greedy with a stack: scan the digits; while the previous kept digit is larger than the current one and you can still remove digits, drop it. A smaller digit earlier always beats anything later. If removals remain at the end, cut from the back. Strip leading zeros.

Islands with DFS, shortest path with BFS

Grids are graphs in disguise. To count islands of 1s, scan every cell; each unvisited land cell starts a new island, and a flood fill (DFS with a stack or recursion) marks its whole island. For the shortest route, use BFS with a queue instead: it explores in rings of equal distance, so the first time it reaches the goal is the shortest. In the chapter's version, 0s are sensors, every cell next to a sensor (including diagonals) is unsafe, and the route runs from any cell of the first column to any cell of the last.

Infix, postfix and prefix expressions

  
Humans write infix (3 + 4 * 2); machines prefer postfix (3 4 2 * +), which needs no parentheses or precedence rules: read left to right, push numbers, and an operator pops two operands and pushes the result. Converting infix to postfix uses an operator stack (Dijkstra's shunting-yard). Watch the evaluation.
