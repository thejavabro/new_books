Arrays and strings in a nutshell

An array is a fixed-size block of contiguous memory, so a[i] is one address calculation: base + i × element size. That is why indexing is O(1) while inserting in the middle is O(n): everything after it must move. A Java String is an immutable sequence of chars (internally bytes since Java 9); every "change" creates a new string, so build text in a loop with StringBuilder. Pick an index to see the arithmetic.

Ask before you codeASCII or Unicode? Case-sensitive? Can I modify the input? Extra memory allowed? For strings, Unicode matters: characters outside the Basic Multilingual Plane (many emoji) take two chars, a surrogate pair. The chapter has a problem on extracting their code points with codePointAt.

Matrix tricks: rotate 90° and spread the zeros

  
Rotate an n × n matrix in place

  
Work layer by layer from the outside in. In each layer, every element moves in a cycle of four: top → right → bottom → left → top. Saving one value lets you rotate the other three without extra arrays: O(n²) time, O(1) space.

  

    

    
void rotate(int[][] m) {                  // clockwise
    int n = m.length;
    for (int layer = 0; layer < n / 2; layer++) {
        int first = layer, last = n - 1 - layer;
        for (int i = first; i < last; i++) {
            int off = i - first;
            int top = m[first][i];
            m[first][i] = m[last - off][first];   // left  -> top
            m[last - off][first] = m[last][last - off]; // bottom -> left
            m[last][last - off] = m[i][last];     // right -> bottom
            m[i][last] = top;                     // top   -> right
        }
    }
}

  

  
Matrix containing zeros

  
If a cell is 0, set its whole row and column to 0. The trap: zeroing as you scan spreads new zeros everywhere. First record which rows and columns contain a zero, then zero them. (The space-saving version stores those flags in the first row and column.) Tap cells to place zeros.

Two pointers: container with the most water

  
Given heights, pick two lines that hold the most water with the x-axis: area = width × the shorter height. Start with the widest pair. Moving the taller line inward can never help (the shorter one still limits the height and the width shrinks), so always move the shorter one. One pass: O(n).

  

  
int maxArea(int[] h) {
    int lo = 0, hi = h.length - 1, best = 0;
    while (lo < hi) {
        best = Math.max(best, (hi - lo) * Math.min(h[lo], h[hi]));
        if (h[lo] < h[hi]) lo++; else hi--;
    }
    return best;
}

Trapping rainwater

  
Water above each bar is min(max on the left, max on the right) − height. Two pointers avoid storing both max arrays: whichever side has the lower max is settled, because the other side is guaranteed to be at least as tall.

  

  
int trap(int[] h) {
    int lo = 0, hi = h.length - 1, leftMax = 0, rightMax = 0, water = 0;
    while (lo < hi) {
        if (h[lo] < h[hi]) {
            leftMax = Math.max(leftMax, h[lo]);
            water += leftMax - h[lo++];
        } else {
            rightMax = Math.max(rightMax, h[hi]);
            water += rightMax - h[hi--];
        }
    }
    return water;
}

Sliding window: longest substring without repeats

  
Grow a window to the right one character at a time. When the new character is already inside the window, jump the left edge just past its last occurrence. Remember each character's last index in a table (256 entries for extended ASCII) and the whole thing is O(n).

  

  
int longestDistinct(String s) {
    int[] last = new int[256];
    Arrays.fill(last, -1);
    int best = 0, left = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (last[c] >= left) left = last[c] + 1;   // shrink past the repeat
        last[c] = right;
        best = Math.max(best, right - left + 1);
    }
    return best;
}

Rotating an array k times with three reversals

  
Rotate right by k: reverse the whole array, then reverse the first k elements, then the rest. Each element moves exactly where it should, in place, in O(n). (Use k % n first.)

  

    

    
void rotateRight(int[] a, int k) {
    k %= a.length;
    reverse(a, 0, a.length - 1);
    reverse(a, 0, k - 1);
    reverse(a, k, a.length - 1);
}
void reverse(int[] a, int i, int j) {
    while (i < j) { int t = a[i]; a[i++] = a[j]; a[j--] = t; }
}
