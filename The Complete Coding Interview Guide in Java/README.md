# The Complete Coding Interview Guide in Java — Visual Companion

An interactive, browser-based study companion for *The Complete Coding Interview Guide in Java* (Anghel Leonard, Packt, 2020). Each page covers the core concepts of a chapter and a representative selection of its problems, with short original Java solutions, animated step-through walkthroughs, diagrams and quick quizzes.

## How to open it

Unzip the folder and open `index.html` in any modern browser. No internet connection or installation is needed (fonts fall back gracefully offline). Pages support light and dark themes and work on phones and desktops.

## Note on content

All explanations, diagrams, and Java solutions are original summaries and re-implementations written for study purposes; they are not copied from the book. Problems were chosen to be representative of each chapter rather than exhaustive (the book has 200+ problems).
