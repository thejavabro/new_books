Trees and Graphs

Trees and graphs are the trickiest data structures in interviews, and the most visual. Draw them, traverse them in the right order, and most problems become a short recursive function.

1

Trees in a nutshell

A tree is a set of nodes where each node has one parent (except the root) and any number of children, and there are no cycles. Interviews mostly use binary trees (at most two children). The names below get mixed up constantly, so learn them with a picture.

2

Binary search trees and the four traversals

In a BST every node is greater than everything in its left subtree and smaller than everything in its right. Search, insert and delete follow one path from the root: O(h), which is O(log n) when balanced and O(n) when the tree degenerates into a line. Insert values, then play a traversal. In-order on a BST visits values in sorted order.

void inOrder(Node n, List<Integer> out) {   // left, node, right
    if (n == null) return;
    inOrder(n.left, out);
    out.add(n.value);
    inOrder(n.right, out);
}
// pre-order: node, left, right   post-order: left, right, node
// level-order: a queue, one level at a time
3

Binary heaps

A min-heap is a complete binary tree where every parent is ≤ its children, stored in a plain array: the children of index i live at 2i+1 and 2i+2, the parent at (i−1)/2. Insert appends and sifts up; removing the minimum moves the last element to the root and sifts down. Both are O(log n). Java's PriorityQueue is exactly this.

4

Graphs: representation and traversal

A graph is nodes plus edges, with no root and possibly cycles, so traversals must remember what they visited. Store it as an adjacency matrix (n × n booleans: O(1) edge check, O(n²) memory) or an adjacency list (each node's neighbors: memory proportional to edges, the usual choice). BFS uses a queue and explores in rings; DFS uses a stack (or recursion) and goes deep first.

frontier: 
List<Integer> bfs(List<List<Integer>> adj, int start) {
    List<Integer> order = new ArrayList<>();
    boolean[] seen = new boolean[adj.size()];
    Queue<Integer> q = new ArrayDeque<>(List.of(start));
    seen[start] = true;
    while (!q.isEmpty()) {
        int u = q.poll();
        order.add(u);
        for (int v : adj.get(u)) if (!seen[v]) { seen[v] = true; q.add(v); }
    }
    return order;
}
5

Sorted array to a minimal-height BST

To keep the tree as short as possible, the root must be the middle element, so that each side holds half. Recurse on the left half and the right half. Each element is placed once: O(n).

Node build(int[] a, int lo, int hi) {
    if (lo > hi) return null;
    int mid = (lo + hi) >>> 1;
    Node n = new Node(a[mid]);
    n.left = build(a, lo, mid - 1);
    n.right = build(a, mid + 1, hi);
    return n;
}
6

Is this binary tree a BST? Pass down the bounds

Checking only each node against its children is a classic mistake: a deep node can be fine locally and still break the rule with an ancestor. Pass a (min, max) range down instead: going left tightens max, going right tightens min. Toggle the trap below.

boolean isBst(Node n, long min, long max) {
    if (n == null) return true;
    if (n.value <= min || n.value >= max) return false;
    return isBst(n.left, min, n.value) && isBst(n.right, n.value, max);
}
// call: isBst(root, Long.MIN_VALUE, Long.MAX_VALUE)
7

Topological sort: build order with dependencies

Given tasks and "a must come before b" edges in a directed acyclic graph, list the tasks in a valid order. Kahn's algorithm: count incoming edges; repeatedly take a task with none left, output it, and remove its outgoing edges. If tasks remain but none is free, there is a cycle.

List<Integer> topo(int n, int[][] edges) {        // edge: {before, after}
    List<List<Integer>> adj = new ArrayList<>();
    int[] in = new int[n];
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    for (int[] e : edges) { adj.get(e[0]).add(e[1]); in[e[1]]++; }
    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (in[i] == 0) q.add(i);
    List<Integer> order = new ArrayList<>();
    while (!q.isEmpty()) {
        int u = q.poll();
        order.add(u);
        for (int v : adj.get(u)) if (--in[v] == 0) q.add(v);
    }
    if (order.size() != n) throw new IllegalStateException("cycle");
    return order;
}

Chess knight: fewest moves with BFS

The fewest knight moves between two squares is a shortest path in an unweighted graph whose nodes are squares and whose edges are knight moves: BFS. Tap a square to set the start, tap another to set the target. Shading shows the BFS distance rings.

Lowest common ancestor and other tree classics

For a plain binary tree (not necessarily a BST), recurse: if the current node is one of the two targets, return it; if the targets are found in different subtrees, the current node is the lowest common ancestor; otherwise pass up whichever side found something.

Node lca(Node n, Node p, Node q) {
    if (n == null || n == p || n == q) return n;
    Node left = lca(n.left, p, q);
    Node right = lca(n.right, p, q);
    if (left != null && right != null) return n;   // split here
    return left != null ? left : right;
}
