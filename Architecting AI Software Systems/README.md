# Architecting AI Software Systems: visual companion

Interactive, visual study pages for *Architecting AI Software Systems: Crafting robust and scalable AI systems for modern software development* by Richard D Avila and Imran Ahmad (Packt, 2025). There is one page per chapter, with diagrams you can click, small simulations, step-through walkthroughs, sorting games and a short quiz at the end of each page.

## How to open
Unzip the folder and open `index.html` in any modern browser. Each page is self-contained, with all CSS and JS inlined. Pages work offline; Google Fonts load when you are online, and system fonts are used otherwise. There is a light/dark theme toggle in each page header, and pages follow your system setting by default.

## Notes
- All explanations are original summaries written for these pages, not text copied from the book. Diagrams are redrawn ideas.
