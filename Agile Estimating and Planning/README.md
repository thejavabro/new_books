# Agile Estimating and Planning: visual companion

Interactive study notes, one page per chapter (23 chapters), with diagrams, animations, simulators and quick checks.

## Use it
- Unzip into `C:\repo\new_books\Agile Estimating and Planning` (or anywhere).
- Open `index.html` in any browser (double-click it). No install or build step.
- Every page links to the previous and next chapter and back to the index.

Fonts load from Google Fonts. Offline, the pages fall back to system fonts and still work.
