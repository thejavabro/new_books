# Designing Distributed Systems: a visual companion

An interactive, chapter-by-chapter study companion to *Designing Distributed Systems* (2nd edition, Brendan Burns, O'Reilly). Each page explains one chapter (or a pair of short ones) with diagrams, animations, small simulations you can play with, and a short self-check quiz.

All explanations, diagrams, examples and code snippets are original summaries written for this companion. They are not text from the book; read the book for the full treatment.

## How to open

Unzip the folder and open `index.html` in any modern browser. Everything works offline (only a Google Fonts stylesheet is requested, with system-font fallback). Pages link to each other with relative links; light and dark mode follow your system setting and can be toggled.
