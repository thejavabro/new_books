A webapp in a handful of lines

Ask a room of Python programmers which web framework to use and you'll get more opinions than people. The book picks Flask, a "micro-framework" installed from PyPI with pip install flask. It does the essentials and stays out of your way. A request comes in for a URL, Flask finds the function registered for that URL, runs it, and sends whatever it returns back to the browser.

Anatomy of a minimal Flask app

Here is a tiny app in the shape the book uses. Four of its lines appear in nearly every Flask app. Tap a line to see what it does.

Dunder name, dunder main

Python sets __name__ to "__main__" only in the file you run directly. The if at the bottom therefore starts the test server when you run the app yourself, and does nothing when a cloud host imports your module and starts it its own way.

Decorators map URLs to functions

The @app.get("/swimmers") line is a decorator: it wraps the function underneath and registers it with Flask for that URL and HTTP method. GET is what browsers send when you visit a page; POST is what a form sends when you submit it. Type a path, pick a method, and see which function fires.

Why global variables bite on a server

One function builds the list of swimmers; another needs it. Inside a function, a variable is local, so the second one hits a NameError. Making it global "works" on your laptop, but a real web server handles many users at once, and they would all share (and overwrite) that one global. Flask's session is a dictionary kept per visitor, tied to a cookie signed with your app.secret_key. Play both users.

Templates keep HTML out of your Python

Flask bundles the Jinja2 template engine. A template is HTML with holes: {{ expression }} inserts a value, and {% statement %} runs logic such as a for loop. render_template("select.html", title=..., data=...) fills it in. A shared base.html defines the page skeleton with named {% block %}s, and other templates {% extends "base.html" %} and fill only those blocks. Edit the template or the data below.

Form data arrives as a dictionary

A drop-down built by a Jinja loop sits inside an HTML <form method="POST">. When the Coach submits it, Flask exposes the fields as the dictionary request.form, keyed by each input's name. Square brackets get the value out. The book also leans on default parameter values: a parameter given a value in the def line becomes optional.
