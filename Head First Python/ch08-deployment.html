One stylesheet, inherited by every template

The first version of the Coach's app looks very 1990s. A small CSS file fixes that. Flask serves files like stylesheets and images from a folder called static, and templates live in templates. Add one <link> tag to base.html and every template that extends it picks up the style. Toggle the link and watch which pages change.

Quick fix or clean fix?The bar-chart page is built by an f-string in swimclub.py, not from a template, so it misses out. The quick fix adds one line of HTML to that f-string. The cleaner fix moves the chart's HTML into a Jinja template too, keeping logic in Python and presentation in templates. The book takes the quick fix here and does the clean one in chapter 13.
2

Tidy labels with expressions inside {{ }}

The event drop-down showed raw filenames like Katie-9-100m-Free.txt. Jinja runs real Python-like expressions between {{ and }}, so the template can tidy the label while the form still sends the full filename as the option's value. Keep these expressions short; anything complicated belongs in Python code.

Ten steps to the cloud

  
Code that only runs on your laptop helps nobody. The book deploys to PythonAnywhere, a Python-focused host whose free beginner account allows one webapp, and Flask code usually runs there unchanged. Step through the process.

  

    

    

  

  
Zip it, don't drip itUploading files one by one through a web page is a reliable way to forget one. Zip the whole webapp folder (code, templates, static, data) and unzip it in the host's console.






  
4
WSGI: the plug between server and app

  
Locally, app.run() starts Flask's own small test server. In production a proper web server handles the network, and it talks to your Python code through WSGI, the Web Server Gateway Interface (said "whiskey"). It is a standard plug: any WSGI server can run any WSGI app. On PythonAnywhere a short WSGI file tells the server which folder holds your code and which object is the app; you edit two lines so it points at your folder and imports app from app.py.
