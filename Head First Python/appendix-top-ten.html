A beginner's book has to stop somewhere. The appendix lists ten topics worth learning next. Tap one for a short summary; the more interesting ones get a small demo further down.

2

Do you really need a class?

You built a whole webapp without the class keyword. Python fully supports object-oriented programming, but it doesn't make you start there. Before writing a class, ask three questions in order. Answer them to see where you land.

from dataclasses import dataclass

@dataclass
class Swim:
    swimmer: str
    event: str
    time: str

s = Swim("Darius", "100m Fly", "1:28.47")   # __init__ and __repr__ written for you

When you do write classes, the dunders stop being ignorable: __init__ sets up a new object, __repr__ controls how it prints, and __enter__/__exit__ are how a context manager like DBcm hooks into with.

3

Catch errors instead of coding around them

Throughout the book, errors were avoided by checking first (is there a colon?). The other strategy is to try the operation and handle the exception if it happens, with try/except. Feed the function different inputs.

def safe_hundredths(t):
    try:
        mins, rest = t.split(":")
        secs, hund = rest.split(".")
        return int(mins) * 6000 + int(secs) * 100 + int(hund)
    except ValueError as err:
        print("Skipping bad time:", t, "-", err)
        return None

The walrus operator and match

:= (an "assignment expression", nicknamed the walrus for its eyes and tusks) assigns a value and uses it in the same expression, often saving a line. Its arrival caused a famously heated debate in the Python community; use it if you like it. And Python had no switch for nearly thirty years: a chain of if/elif did the job. Since 3.10, match/case offers structural pattern matching. Pick a stroke.

if (n := len(times)) > 5:
    print(f"{n} times: that's a long session")

match stroke:
    case "Fly":
        name = "butterfly"
    case "Back" | "Breast":
        name = stroke.lower() + "stroke"
    case "Free":
        name = "freestyle"
    case _:
        name = "unknown"

Doing several things at once

Downloading ten pages one after another means ten waits in a row. Most of that time is spent waiting on the network, not computing. Python offers threads, processes and asyncio to overlap the waiting. Compare the timelines.
