The dataframe: rows, columns and an index

Tabular data is everywhere: record tables, bank statements, spreadsheets. In Python the go-to library is pandas, imported by near-universal convention as import pandas as pd (the as keyword gives a module a short alias). Its central structure is the dataframe: a table with labelled columns and a labelled row index. Tap the parts.

A dataframe with a default index of 0, 1, 2…

2

One call scrapes every table on a page

Chapter 9 fetched, parsed, searched and looped. pandas has pd.read_html(url), which fetches the page and returns a list of dataframes, one per <table>. As before, you find the four you want among them, and df.head() shows the first five rows so you can check what you've got.

import pandas as pd
tables = pd.read_html(URL)
len(tables)                 # more tables than you wanted, as before
lc_men = tables[0]
lc_men.head()               # first five rows
lc_men[["Event", "Time"]]   # select just two columns
3

Selecting columns and filtering rows

Index a dataframe with a list of column names to keep only those columns. Index it with a boolean condition to keep only the rows where the condition is true. To drop the relays you want the rows that do not contain "relay"; pandas uses ~ to negate a condition (Python's not doesn't work element by element).

4

Bending a dataframe into your dictionary

The webapp already expects a dictionary of event to time. to_dict converts a dataframe to a Python dictionary, and its orient argument controls the shape. The default is keyed by column, which isn't it. "records" gives a list of row dictionaries: closer, not quite. The trick that works is to make Event the index with set_index, keep the Time column, and convert that.

Fewer lines isn't automatically better

  
The pandas version is much shorter than the gazpacho one. That doesn't make it the winner by default. pandas is a large dependency that you need to learn; gazpacho code is plain loops you can read line by line and adapt when a page changes. Use pandas when you'll do real analysis on the tables; for a small scrape, either is fine.

  

    
gazpacho: explicit
html = gazpacho.get(URL)
soup = gazpacho.Soup(html)
tables = soup.find("table", {"class": "wikitable"}, mode="all")
for table in tables[:4]:

for df in tables[:4]:
