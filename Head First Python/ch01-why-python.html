Six reasons people pick Python

Python does the usual things: variables, loops, conditionals, functions. What sets it apart is a handful of choices about how those things look and what comes in the box. The book distils them into six points, and the rest of the chapter touches on each one with a tiny card-dealing example.

Curly braces hold data, not codePython marks a block with a colon and indentation instead of braces, and most statements don't need a semicolon. The convention is four spaces per level, and you must not mix tabs and spaces in the same file.

Run code one cell at a time

The book runs almost everything in a Jupyter notebook inside VS Code. A notebook is a stack of cells. Each one is a small editor, and Shift+Enter runs the selected cell, prints its result underneath and moves you on. Plain Enter just adds a new line, because it is already taken. Behind the scenes each cell goes to Python's REPL (read, evaluate, print, loop), and variables made in one cell stay available in later ones.

Why a set models a deck better than lists

The first version of the card dealer keeps suits and faces in two lists and picks one of each with random.choice. That gives a random card, but nothing stops the same card coming up twice: the lists never change. The fix is a better data structure. A set holds unique values and gives you one-step add and remove, so a drawn card can actually leave the deck. One wrinkle: random.choice needs something it can index, so you hand it list(deck), a list copy of the set.

Ask any object what it can do

  
Everything in Python is an object, and objects carry attributes, many of which are methods. The built-in dir lists them; wrapping it in print lays the list across the screen instead of down it. The book calls print(dir(x)) the "combo mambo". Names wrapped in double underscores (the "dunders") are special hooks you can ignore for now. When a name looks useful, help shows its documentation without leaving the notebook.

Membership with inin does two jobs. In a for loop it names what to iterate over. On its own it is a search: ("Hearts", "Ace") in deck is True or False, which makes it ideal in an if. Python's two booleans are spelled True and False.

The standard library and PyPI

  
Python's guiding idea is that you should only write new code when you have to. The built-in functions (BIFs) such as len, type, range and sorted work on many kinds of object. Beyond them is the Python Standard Library (PSL): a large, decades-tested collection of modules that ships with every install, which is what "batteries included" means. Beyond that is PyPI, the Python Package Index, a public repository of third-party packages you install with pip.
