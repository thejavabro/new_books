From notebook cells to a function

Everything from chapters 2 and 3 already works, but only inside one notebook, for one hard-wired file. A function packages that code so it can run for any filename. def names it, the parameters in parentheses are its inputs, the colon opens its indented body, and return sends the answer back. A docstring under the def line documents it, and help() will show it. Tap each part.

Save it as a module, then import it

Put the function in a file ending in .py and you have a module. Any notebook or program in the same folder can import swimclub and call swimclub.read_swim_data(...) by its fully qualified name. Copying only the function isn't enough, though: it relies on things defined elsewhere, like FOLDER and the statistics import. Toggle what goes into the module and see whether the call works.

Functions return one thing: often a tuple

A Python function only ever returns a single object. Write return a, b, c and those values are bundled into one tuple. Tuples are like lists that cannot change once made: ordered, indexable, immutable. You can index into the result, or unpack it straight into variables as in chapter 2.

4

Detective work on sixty files

The os module in the standard library talks to your operating system. os.listdir(FOLDER) returns a list of every filename in the folder, ready for a for loop. The Coach has sixty files, yet the list holds sixty-one. Run the loop below and find out what's wrong.

swim_files = os.listdir(swimclub.FOLDER)
for n, fn in enumerate(swim_files, 1):
    print(n, "Processing:", fn)
    swimclub.read_swim_data(fn)

sort changes the list; sorted makes a copy

Lists come with about a dozen methods (append, remove, sort, reverse, pop and so on). Be careful with the ones that work in place: sort() rearranges the list itself and returns None, so the old order is gone. The sorted() BIF returns a new, ordered list and leaves the original alone.

Decisions: is there a colon in the time?

The crash came from a 50m file: short races record times like "43.86", with no minutes. The code assumed every time had a colon. Rather than edit the stopwatch's data, change the code: use in to check for a colon, and if/else to handle both shapes. Type a time and watch the path it takes.

if ":" in t:
    minutes, rest = t.split(":")
    seconds, hundredths = rest.split(".")
else:
    minutes = 0
    seconds, hundredths = t.split(".")
