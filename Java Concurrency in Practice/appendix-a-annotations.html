Class annotations: what does this class promise?

The book uses three class-level annotations to state a class's thread-safety promise. They help users (is it safe to share?), maintainers (must I keep it safe?) and tools (static analysers can check the claim).

@ImmutableThe class is immutable. Implies @ThreadSafe.
@ThreadSafeSafe to use from multiple threads with no extra coordination by callers.
@NotThreadSafeOptional: unannotated classes should be presumed not thread-safe, but this makes it explicit.

@GuardedBy: which lock guards what

Field and method annotations are for maintainers. A thread-safe class often stops being thread-safe when someone later adds a field without guarding it, or a method that forgets the lock. @GuardedBy(lock) records which lock must be held to access a field or call a method. The lock argument can take five forms; tap each.
