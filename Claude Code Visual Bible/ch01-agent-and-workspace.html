Understand Claude Code and Set Up a Workspace

Claude Code is an agent that reads, writes and runs things inside a folder on your computer. You direct it and check it. First you need a clear picture of its loop, then a workspace for it to work in.

1

From chat assistant to coding agent

In a chat, Claude reads your message and writes back. Nothing outside the conversation changes. Claude Code is an agent: it carries out a multi-step task using tools, opening your project folder, reading what's there, writing files and running commands such as a local preview. That is why it needs a folder on your own computer and, later, a terminal. Toggle between the two to see where the work happens.

Being an agent doesn't mean working without you. Think of a capable assistant who checks in at each stage and stops before anything risky or irreversible, not a search engine.

2

You direct the work; Claude writes the code

This is not a programming course. Picture yourself as the creative director of a small team: you don't do every specialist task, but you give clear direction, recognise good work and notice problems. Claude supplies syntax; you supply purpose, taste, judgment and the final yes. The working rhythm the book repeats:

3

The six-stage loop every task follows

From a one-line fix to a whole feature, every request travels the same circle. Blue stages are yours, orange are Claude Code's. A big project is just many small trips round it.

The one-shot mythClaims that one perfect prompt yields a finished product ignore everything else that shapes the result: what's in the folder, which files exist, what you approved last session. Expect the first attempt to get you close, and plan one or two review-and-revise rounds as normal, not as failure.
4

What still needs human judgment

Claude Code plans, writes and tests faster than you can type, which is exactly why review matters: it doesn't know your users, your taste or your business, and can't tell on its own whether working code is the right result. A page can look fine and still hide a broken link, a wrong price or a privacy problem. Decide which of these you can leave to Claude and which must stay with you.

Delegate or decide?

5

Pick an idea small enough to picture finished

Before installing anything, choose one thing you'd enjoy building, real or imaginary: a page for a hobby, a tracker for a habit or reading list, a site for a local club, a quiz on a topic you love. It needn't be practical or original, just specific enough for one sentence. Small beats grand: "a website for my bakery" is easier to hold in your head than "a platform for local businesses". You can also ask Claude (in chat, no Claude Code needed) to interview you and suggest five ideas.

Small enough for a first build?

6

Install VS Code and the Claude Code extension

The workspace is VS Code (Microsoft's free editor) with Anthropic's Claude Code extension inside it: files, editor and Claude side by side in one window. Tap the numbered parts of the sketch, then tick off the setup as you go.

May have changed since publicationThe book's steps name specific labels: the extension "Claude Code for VS Code" (with a quoted download count), the Command Palette entry "Claude Code: Open in New Tab", a "Claude.ai Subscription" sign-in choice, and Auto mode as the default. Install flows, labels and defaults are the kind of detail the author moves to his online changes page. Check Anthropic's current VS Code setup guide (code.claude.com/docs) if anything looks different.
7

Give every project its own empty folder

Claude Code reads and edits files inside the folder you open, and it can see everything there. Point it at your whole Documents folder and it can see your tax return too. Compare the two choices.

Once the folder is open, confirm the connection with a harmless question before anything real:

Can you see the files in this folder? Describe what is here in plain language.

In a fresh folder the right answer is "it's empty". A sign-in prompt or an error means you should repeat the sign-in. If you also have another AI extension installed (GitHub Copilot Chat, say), make sure you are typing into the Claude panel.
