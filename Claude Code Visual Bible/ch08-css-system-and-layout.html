Design tokens: decide once, reuse everywhere

A design token is a named, reusable value: "primary blue", "space-2", "radius". Define it once and every rule refers to it by name, so five buttons can't drift into five slightly different blues, and one later change updates everything. In CSS these live as custom properties at the top of the stylesheet. Every element is also a box: content, then padding, a border, then margin. Spacing tokens control those layers.

Contrast is not a matter of tasteLight grey on white can be unreadable for many visitors, whatever it looks like on your screen. Accessibility checks usually measure against WCAG: AA asks for at least 4.5:1 for normal text and is what most laws and real sites aim for; AAA asks for 7:1 and suits narrower needs. Passing AA but not AAA is normally fine.

Name your own font pairing

  
Left to itself, Claude tends to reach for the same few fonts (Inter, Roboto, the system font) on every project. They're fine fonts, but defaults are why so many AI-built sites look alike. Naming a pairing gives the site an identity: one font with character for headings, one very readable font for body text. Try the book's four suggestions, all free on Google Fonts. (Without an internet connection these fall back to your system font.)

Flexbox for one direction, Grid for two

  
Layout decides how boxes relate: stacked, side by side, evenly spaced. Flexbox arranges items along one row or column; Grid arranges rows and columns at once. HabitTrail's hero (heading, description, button stacked and centred) is a Flexbox job; its row of feature cards is a Grid job. Ask Claude which tool fits a section before it writes layout code. Change the tool and the number of items.

See the layout with your browser's Developer Tools

  
Every browser has Developer Tools built in: F12 or right-click → Inspect (Cmd+Option+I on a Mac). Use the element picker, click a feature card, and look for display: grid or display: flex in the styles panel. In Chrome and Edge a small grid/flex badge beside the element draws the real columns and gaps on the page. Pointing at the exact element first means your request to Claude can name the tool instead of describing the problem vaguely.

Relationships, not pixel coordinates

  
Nudging cards into place with exact positions works until content changes. A hobbyist in the book spent evenings re-nudging every project card each time he added one. Grid describes a relationship ("three equal columns") that absorbs new items. Add a fourth card to both versions.
