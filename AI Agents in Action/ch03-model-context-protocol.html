Actions with the Model Context Protocol

MCP is a JSON-RPC 2.0 standard that lets any agent discover and use tools, data and prompt templates without custom glue. This page opens the plug and shows what travels through it.

1

The standardization problem

Before MCP, each framework had its own tool schema, each data source its own access code, and every new pairing meant new glue. Tap each problem to see how MCP answers it.

2

Three parts: client, server, service

An MCP client lives inside a host (Claude Desktop, an IDE, or your agent). It connects to an MCP server, a small program that fronts some service or resource: a filesystem, an API, a database. An agent is just one more kind of client. Click a box.

3

What actually travels on the wire

Every exchange is a JSON-RPC 2.0 message. Step through a session: handshake, discovery, a call, a result.


    

  






  
4
Three building blocks

  
Tools are actions the model can invoke (they may change things). Resources are data the client can read, addressed by URI. Prompts are reusable templates the server offers. An agent can treat any of them as callable verbs. Sort these.

Transports: STDIO vs SSE

  
The same server can speak over two transports. Switching is literally a constructor swap in the agent code.

  

    

    

    

  






  
6
Local, remote, or a mix

  
A single server is either local or remote; real agents connect to several at once, mixing both. Keep sensitive things local, share heavy APIs remotely. Toggle where each server runs.

A server in a dozen lines

  
With the Python SDK's FastMCP, a decorated function becomes a tool. The function name, docstring and type hints become the schema the model reads, which is why clear names and docstrings matter so much.

10
Agents as servers: LEGO composition

  
An entire agent (with its own reasoning and tools) can be wrapped as an MCP server, so another agent calls it like any tool, with typed inputs and outputs end to end. Each block stays isolated, testable and swappable. Swap a block and nothing else changes.
