The Cognitive Agent

CoT, ReAct, tree-of-thought and Reflexion are cognitive primitives: individual skills. A cognitive architecture decides which skill a problem needs, watches whether it is working, and changes course when it is not. That watching is metacognition.

Cognition and metacognition, defined as engineering

No claims about consciousness. Cognition is the quality of the agent's internal model of the task. Metacognition is its ability to monitor its own reasoning. Tap each capability for the behaviour with and without it.

The cognitive agent architecture

A shared cognitive workspace sits in the middle. Five modules read and write it: perception, planning, execution, evaluation and attention. A seventh component, memory, persists experience in a knowledge graph through the official MCP memory server. Click a module.


  






  
6
Watch the cognitive cycle

  
The default cycle is perceive → plan → execute → evaluate, but attention can break it at any point. Pick a query: a familiar simple one takes the system 1 fast path; a messy one goes deep and may re-plan.

  

    

    

    

  






  
7
Confidence-gated execution

  
The simplest and most valuable metacognitive pattern: before presenting anything, check the workspace's confidence state structurally (not "I think…" in the text). This gate follows the logic in the chapter: below 0.3 signal uncertainty; 0.3–0.6 gather more if budget remains; unresolved contradictions or three falling readings in a row also mean gather more.

  

    

      

      

    

    

    

    

  






  
8
Stagnation detection and pivoting

  
The broken-record failure: retrying the same query with the same phrasing. Compare the last two steps' findings; heavy overlap or flat confidence means stuck. Attention then routes to meta-planning, which records the failed strategy so it is not repeated, now or in future sessions.

  

    

    

  






  
9
Memory that compounds

  
The memory module wraps the MCP knowledge graph: problem types as entities, successful strategies as observations, links between related problems as relations. It retrieves before planning and records after evaluation. Solve tasks and watch the graph, and the agent, improve.

11
Measuring it: calibration and friends

  
Four production metrics: cognitive efficiency (steps vs the optimum), metacognitive calibration (does confidence track correctness?), adaptation rate (iterations from stagnation to a successful pivot) and knowledge-boundary accuracy (false alarms vs confident hallucinations). Calibration is easiest to see.
