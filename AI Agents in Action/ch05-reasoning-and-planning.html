Agent Reasoning and Planning

LLMs predict tokens; they do not think by default. Agents get multistep reasoning by structuring it: write the steps out, interleave them with tool calls, explore branches, and critique their own work.

1

Chain-of-thought: show your working

Asked cold, a model pattern-matches to an answer. Asked to reason step by step, it writes intermediate results it can build on, and you can debug them. The price is extra tokens and latency.

Puzzle. A time traveller starts in 2030, jumps back 45 years, forward 12, then back 7. They live there for 3 years and jump forward 20. What year is it?

ReAct: reason, act, observe, repeat

ReAct interleaves thoughts with tool calls. Each observation feeds the next thought, so the agent can correct itself with real data instead of guessing. Step through a run.

Question. Is it warmer right now in the capital of Australia or the capital of Canada?
Weather values are made up for the demo.
3

Planning: draft, then revise

For bigger goals, ask the LLM for a strategic outline first, then execute it step by step and revise the plan when real-world feedback arrives.

Goal. Publish a blog post comparing three vector databases by Friday.
4

Tree-of-thought: explore, score, prune

Instead of one chain, generate several candidate thoughts, have the model rate each ("sure / maybe / impossible"), prune the losers and expand the best. Powerful for search-like problems, and very token hungry. Task: make 24 from 4, 9, 10, 13 using + − × ÷.

5

Reflexion: solver and critic

Reflexion wraps any strategy in a loop: a solver attempts, a critic (or a test) checks, the critic's written feedback is stored as a reflection, and the solver tries again with it, until the check passes or attempts run out.

Task. Write is_palindrome(s). Tests include "Racecar" and "A man, a plan, a canal: Panama".

7

The sequential thinking MCP server

A universal scratchpad exposed as a tool. The agent writes numbered thoughts to it, can revise an earlier thought or branch from one, and says when it needs more thoughts than planned. It works alongside ReAct or ToT.


  






  
8
Stacking strategies

  
Strategies compose: CoT drafts a plan, ReAct (with ToT where it branches) executes it, Reflexion grades and retries. Each layer buys reliability and costs latency. Toggle the layers.
