The Rise of AI Agents

An agent is an LLM with agency: it can decide, plan and act toward a goal on someone's behalf, using tools, memory and planning. This page walks from plain chat to teams of agents.

Autonomous does not mean unsupervised

Production agents use graduated human-in-the-loop controls. Low-risk steps run on their own, medium-risk steps ask for a quick confirmation, and high-stakes actions need explicit approval no matter how autonomous the agent is. Sort these actions.

3

Thinking like an agent: sense, plan, act, learn

Agency runs as a loop. The agent senses its situation, plans the next move, acts with a tool, then learns from the result and goes round again until the goal is met. Follow one goal through two laps.

goal

"Plan a three-day Lisbon trip under $800."

4

Agents act with tools

Without tools, an LLM can only produce text. Tools (also called actions or functions) wrap APIs, databases and other resources so the agent can reach outside its own code. Pick a request and watch which tools the agent decides to call, and in what order.

5

MCP: one plug for every tool

Before the Model Context Protocol, each agent needed custom glue code for each tool: inconsistent access, fragmented integrations, lots of work. MCP (introduced by Anthropic in November 2024) works like USB-C for LLMs: a tool is wrapped once as an MCP server, and any MCP-speaking agent can discover and use it. Change the counts.
