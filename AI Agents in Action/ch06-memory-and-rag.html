Memory and Knowledge: RAG for Agents

Retrieval is the bridge between raw data and an agent's reasoning. The same retrieval machinery serves two jobs: knowledge (mostly static documents) and memory (things that change as the agent works and talks).

1

Retrieval-augmented generation, end to end

RAG has two halves. Indexing (offline): load documents, split them into chunks, turn each chunk into an embedding vector, store it. Querying (per question): embed the question, find the nearest chunks, paste them into the prompt, generate an answer that cites them.

2

Chunk size and overlap

Chunks too big dilute relevance and waste tokens; too small and they lose context. Overlap keeps ideas that straddle a boundary intact. Chunking on semantic boundaries (sentences, sections) beats blind character counts.

3

4

Cosine similarity in one picture

Similarity is the cosine of the angle between two vectors: 1 means same direction (same meaning), 0 unrelated, −1 opposite. Length does not matter, only direction.

5

Vector, keyword, or both?

Vector search catches meaning but misses exact codes, jargon, numbers and fresh terms. Keyword search (BM25) is the opposite. Hybrid search runs both and merges them, for example with reciprocal-rank fusion: each document scores Σ 1/(60 + rank) across the lists.

6

Memory: borrowed words, real machinery

Agent memory borrows human terms (working, episodic, semantic, procedural) as shorthand. Underneath there are four pieces: the context window, external storage, state management (scratchpads, plans) and retrieval that moves content from storage into the window. Click a memory form to see what implements it.

7

Graph memory answers multi-hop questions

Embeddings find similar text, but "Who reports to Alice's manager?" needs two hops across relationships that no single chunk contains. A graph memory stores entities, relations (edges) and observations, so the agent can walk it, for example through an MCP memory server.

8

Compression and forgetting

Memory stores grow until retrieval gets noisy and expensive. Two remedies: cluster and summarise similar memories into one, and prune stale items nobody has used.

9

Grounding is non-negotiable

Require the agent to cite the passages it used. It pins answers to verifiable sources and gives the agent a reason to say "I don't know" when nothing relevant came back.
